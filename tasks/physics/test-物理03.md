# 构造高质量-query
某超冷中子反射器采用氘化聚合物包覆半径 R=100 nm 的纳米球。为使包覆层产生可实现的吸引性有效界面势,设纳米球芯材及外部匹配基体的相干散射长度密度均为 ρref=1.903×10^−5 Å^−2,而氘化聚合物包覆层的相干散射长度密度为 ρD=6.00×10^−6 Å^−2；因此包覆层相对于匹配背景的散射长度密度差为 Δρ=ρD−ρref=−1.303×10^−5 Å^−2。包覆层厚度 t=2.00 nm,满足 t/R=0.020。将其在固定积分强度的薄层极限下近似为无吸收相干 δ 壳势 V(r)=λδ(r−R),其中 λ=4π(ħ²/2mn)Δρt。

已知中子质量 mn=1.67492749804×10^−27 kg,约化普朗克常数 ħ=1.054571817×10^−34 J·s,且 ħ²/(2mn)=2.07215 meV·Å²。实测中子在 E*=8.2886 neV 处 p 波达到弹性峰顶,即 δ1=π/2(mod π)。

为明确薄层近似的适用精度,规定如下:由峰顶条件反演得到的 λ 与积分强度薄层值 λthin 的相对差不超过 0.2% 时,称二者在"理想 δ 壳参数层面"代数一致；但还必须把有限厚包覆层的层内传播相位 qt 及传递矩阵修正作为独立的模型系统误差进行估计。对有限厚层,相对势深定义为 Vlayer=4π(ħ²/2mn)Δρ,层内波数定义为 q=[2mn(E*−Vlayer)]^1/2/ħ。可用 1−cos(qt) 估计有限厚层传递矩阵对角元相对于理想 δ 壳近似的主要修正量。若该修正在给定有效数字下不可忽略,则不得把 λ 与 λthin 的代数一致直接解释为有限厚实际包覆层已在给定有效数字内复现实测共振位置；实际有限厚模型应预期有相应量级的系统修正。

(1) 由 p 波峰顶条件反演无量纲壳强度 β=2mnλR/ħ² 及 λ,并计算 λthin。按上述 0.2% 标准检验二者在理想 δ 壳参数层面是否一致。再计算 Vlayer、qR、qt 及 1−cos(qt),说明 t/R=0.020 是否足以单独保证有限厚层与理想 δ 壳在共振位置上高精度一致。

(2) 写出 δ 壳势的径向匹配条件,并计算 l=0、1、2、3 的相移；说明是否可在 l=3 截断部分波展开。

(3) 利用部分波振幅及光学定理计算总弹性截面,并计算 θ=90° 时的微分截面。

(4) 判定束缚态的角动量、结合能和简并度。束缚态数的主计数口径规定为不计中子自旋的空间本征态数；同时说明若计入中子自旋 1/2 的二重简并,完整单粒子态数为何值。

# SFT标准-response
1. 基本无量纲参数及理想δ壳强度反演。

R=100 nm=1000 Å,故
ħ²/(2mnR²)=2.07215/1000000 meV=2.07215 neV。

于是
x=kR=[E*/(ħ²/(2mnR²))]^1/2=[8.2886/2.07215]^1/2=2.000。

因此 k=x/R=0.02000 nm^−1=2.000×10^7 m^−1,且 k^−2=2500 nm²。

δ壳势径向方程为
u_l''+[k²−l(l+1)/r²−(2mnλ/ħ²)δ(r−R)]u_l=0。

定义无量纲壳强度
β=2mnλR/ħ²。

令 J_l=ĵ_l(x)=xj_l(x),N_l=n̂_l(x)=xn_l(x)。δ壳匹配给出的相移公式为
tanδ_l=βJ_l²/(βJ_lN_l−x)。

对于 l=1、x=2,
J_1=sin2/2−cos2=0.870796,
N_1=−cos2/2−sin2=−0.701224,
J_1N_1=−0.610623。

p波峰顶 δ_1=π/2(mod π) 对应 tanδ_1 发散,即
βJ_1N_1−x=0。

故
β=x/(J_1N_1)=2/(−0.610623)=−3.2754。

从而
λ=βħ²/(2mnR)=−3.2754×2.07215/1000 meV·Å
=−6.785×10^−3 meV·Å
=−1.087×10^−34 J·m。

2. 积分强度薄层值及有限厚度修正。

由给定材料参数,有限厚包覆层相对于匹配背景的势深为
Vlayer=4π(ħ²/2mn)Δρ
=4π×2.07215×(−1.303×10^−5) meV
=−3.393×10^−4 meV
=−339.3 neV。

固定积分强度薄层极限给出
λthin=Vlayer t=4π(ħ²/2mn)Δρt。

代入 t=20.0 Å,得
λthin=4π×2.07215×(−1.303×10^−5)×20.0 meV·Å
=−6.786×10^−3 meV·Å。

因此,峰顶反演值与积分强度薄层值的相对差约为
|λ−λthin|/|λthin|≈1×10^−4至2×10^−4,
小于题设规定的 0.2%。所以二者在理想δ壳参数层面代数一致。

但是,这并不自动说明真实有限厚包覆层能够在同一有效数字内复现理想δ壳的共振位置。有限厚层中,层内无量纲波数为
qR=[(E*−Vlayer)/(ħ²/(2mnR²))]^1/2
=[(8.2886+339.3)/2.07215]^1/2
≈12.95。

于是
qt=(qR)(t/R)=12.95×0.0200=0.259。

有限厚层传递矩阵的对角元含有 cos(qt),相对于将该层收缩为理想δ壳时,对角元的主要修正量可估计为
1−cos(qt)=1−cos(0.259)≈0.0334,即约 3.3%。

故 t/R=0.020 只说明包覆层在几何上较薄,并不足以单独保证其在共振位置上与理想δ壳高精度一致。反演λ与λthin的约 0.02% 代数符合,是理想δ壳模型内部的参数符合；真实有限厚层仍应预期存在百分之几量级的传播相位或传递矩阵系统修正。若需将实测峰位用于高精度材料验证,应改用有限厚球壳势的完整径向匹配模型,并给出实验峰位不确定度及模型误差预算。

3. 径向匹配、各分波相移和截断。

壳内正则径向解可写为
u_l^<(r)=Aĵ_l(kr),
壳外散射解可写为
u_l^>(r)=B[ĵ_l(kr)cosδ_l−n̂_l(kr)sinδ_l]。

δ壳势在 r=R 给出连续条件和导数跳变条件:
u_l(R+)=u_l(R−),
u_l'(R+)−u_l'(R−)=(2mnλ/ħ²)u_l(R)。

利用 W[ĵ_l,n̂_l]=1,可得
 tanδ_l=βJ_l²/(βJ_lN_l−x)。

在 x=2、β=−3.2754 下:

l=0:
J_0=sin2=0.909297,N_0=−cos2=0.416147,
tanδ_0=0.8360。
取连续支路,
δ_0=0.696 rad。

l=1:
峰顶条件已经给出
δ_1=π/2(mod π)。
取 δ_1=1.571 rad。

l=2:
J_2=(3/x²−1)sinx−3cosx/x=0.396896,
N_2=−(3/x²−1)cosx−3sinx/x=−1.46798,
tanδ_2≈5.63,
δ_2≈1.395 rad。

l=3:
由递推关系
J_3=(5/x)J_2−J_1=0.12144,
N_3=(5/x)N_2−N_1=−2.96873,
tanδ_3≈0.05898,
δ_3≈0.0589 rad。

不能仅因 kR=2 就机械地只保留 s、p 波。这里 d 波的分母 βJ_2N_2−x 接近零,形成 d 波形状共振,因此 δ_2 接近 π/2,必须保留。继续计算 l=4,可得 δ_4约为2.3×10^−3 rad,其对部分波和 Σ(2l+1)sin²δ_l 的贡献约为4.7×10^−5,远小于 l=0至3 的贡献。因此,在理想δ壳散射计算中截断至 l=3 是足够的。

4. 总弹性截面、光学定理和90°微分截面。

定义部分波复系数
a_l=(2l+1)e^(iδ_l)sinδ_l。

由上述相移得到近似值:
a_0=0.492+0.411i,
a_1=3.000i,
a_2=0.861+4.847i,
a_3=0.412+0.024i。

总截面的部分波和为
Σ(2l+1)sin²δ_l
=0.411+3.000+4.846+0.024
=8.281。

因此
σtot=(4π/k²)Σ(2l+1)sin²δ_l
=4π×2500×8.281 nm²
=2.60×10^5 nm²
=2.60×10^−13 m²
=2.60×10^15 barn。

这也满足光学定理
σtot=(4π/k)Im f(0)。

散射振幅为
f(θ)=(1/k)Σ_l a_lP_l(cosθ)。

在 θ=90° 时,cosθ=0,且
P_0(0)=1,P_1(0)=0,P_2(0)=−1/2,P_3(0)=0。

故
f(90°)=(1/k)(a_0−a_2/2)
=(1/k)(0.061−2.013i)。

于是
(dσ/dΩ)|90°=[0.061²+2.013²]/k²
=4.06×2500 nm²/sr
=1.01×10^4 nm²/sr
=1.01×10^−14 m²/sr。

p波在90°方向不贡献振幅,是因为 P_1(0)=0；这并不表示p波散射消失,p波仍处于共振峰顶并对总截面有显著贡献。

5. 束缚态。

取束缚态能量为
E=−ħ²κ²/(2mn),
并定义 y=κR>0。

对于吸引δ壳,每个 l 至多存在一个径向束缚态,出现阈值为
β<−(2l+1)。

本题 β=−3.2754,因此:
l=0 的阈值为 β<−1,满足；
l=1 的阈值为 β<−3,满足；
l=2 的阈值为 β<−5,不满足。

所以只可能存在 s 态和 p 态束缚态。

对于 l=0,壳内 u∝sinh(κr),壳外 u∝e^−κr,束缚态方程为
β=−y[1+coth y]。

代入 β=−3.2754,得
y_0=1.566。

故 s 态结合能为
B_0=y_0²ħ²/(2mnR²)
=1.566²×2.07215 neV
=5.08 neV。

对于 l=1,壳内解可取
u∝cosh y−sinh y/y,
壳外解可取
u∝e^−y(1+1/y)。

相应束缚态方程为
β=[−y−1/(y+1)]−y d/dy[ln(cosh y−sinh y/y)]。

代入 β=−3.2754,得
y_1=0.576。

故 p 态结合能为
B_1=y_1²ħ²/(2mnR²)
=0.576²×2.07215 neV
=0.687 neV。

因此存在两个径向束缚能级:一个 s 能级和一个 p 能级。按不计中子自旋的空间本征态数计,s态有 2l+1=1 个空间态,p态有 2l+1=3 个磁量子数简并空间态,总空间本征态数为 4。若计入中子自旋 1/2 且相互作用不含自旋依赖项,则每个空间态均有二重自旋简并,完整单粒子束缚态数为 8。

## Automated Checks

代码评分只检查最终答复的硬证据，不评价推导过程。本题为多问题目，代码侧对若干可自动确认的关键终值分别抽取并加权。

```python
def grade(transcript: list, workspace_path: str, meta: dict) -> dict:
    import re
    from math import isfinite

    def flatten_text(items):
        parts = []
        for item in items:
            if isinstance(item, dict):
                for key in ("content", "text", "message", "output"):
                    value = item.get(key)
                    if isinstance(value, str):
                        parts.append(value)
            elif isinstance(item, str):
                parts.append(item)
        return "\n".join(parts).lower()

    def normalize_math_text(text):
        """统一符号并剥掉 markdown/LaTeX 装饰，便于抽取数值与单位。

        写法容错（不做容错会把「表述差异」记成「答错」，5 次答复集体假阴性）：
          - markdown 强调：`总数：**4**` 要能命中「总数 4」；
          - LaTeX 装饰壳：`\\text{ cm}^2`、`\\boxed{σ=2.6e7}` 剥壳后单位才可比；
          - Unicode 上标与 `\\times`、`\\beta` 等 TeX 名统一为单字符。
        """
        t = (text
             .replace("−", "-").replace("–", "-").replace("—", "-")
             .replace("×", "x").replace("·", " ").replace("⋅", " "))
        t = t.translate(str.maketrans({
            "⁰": "0", "¹": "1", "²": "2", "³": "3", "⁴": "4", "⁵": "5",
            "⁶": "6", "⁷": "7", "⁸": "8", "⁹": "9", "⁻": "-", "⁺": "+",
        }))
        t = t.replace("\\times", "x").replace("\\cdot", " ")
        for _ in range(3):
            t = re.sub(r"\\(?:boxed|text|mathrm|mathbf|operatorname|rm|bf|it)"
                       r"\s*\{([^{}]*)\}", r"\1", t)
        for tex, ch in (("\\beta", "β"), ("\\sigma", "σ"), ("\\delta", "δ"),
                        ("\\kappa", "κ"), ("\\lambda", "λ"),
                        ("\\approx", "≈"), ("\\simeq", "≈")):
            t = t.replace(tex, ch)
        t = re.sub(r"\\[,;:!> ]", " ", t)
        t = t.replace("$", "").replace("**", "").replace("{", "").replace("}", "")
        return re.sub(r"[ \t]+", " ", t)

    def has_any(text, patterns):
        return any(re.search(pattern, text, flags=re.IGNORECASE) for pattern in patterns)

    def extract_scientific(text, symbol_patterns, exp_range):
        """收集所有「符号=科学计数值」并连带其后的单位文字。

        原实现用 re.search 只取第一处：答复常先写 4π/k²、部分波和等中间量，
        第一处命中的往往不是结论值。这里返回全部候选 (值, 紧随其后的 30 字符)，
        由调用方按单位判定，避免「结论对但被中间量顶掉」的假阴性。
        """
        lo, hi = exp_range
        found = []
        for sym in symbol_patterns:
            patterns = [
                sym + r'\s*[:=≈约-]?\s*\(?\s*(-?[0-9]*\.?[0-9]+)\s*(?:x|\*)\s*10\s*\^?\{?\s*([-+]?\d+)\s*\}?',
                sym + r'\s*[:=≈约-]?\s*\(?\s*(-?[0-9]*\.?[0-9]+)\s*e\s*([-+]?\d+)',
            ]
            for pattern in patterns:
                for match in re.finditer(pattern, text, flags=re.IGNORECASE):
                    exp = int(match.group(2))
                    if lo <= exp <= hi:
                        tail = text[match.end():match.end() + 30]
                        found.append((float(match.group(1)) * (10 ** exp), tail))
        return found

    def extract_plain(text, symbol_patterns):
        """收集所有「符号=普通数值」，而不是只取第一处。

        原实现 re.search 取第一处，会抓到推导中途的 `β = -1/(-0.30528) = +3.2757`
        或阈值判据里的 `β < -1`，把结论正确的答复判成答错（5 次里 3 次假阴性）。
        """
        found = []
        for sym in symbol_patterns:
            for match in re.finditer(sym + r'\s*[:=≈约]?\s*(-?[0-9]+\.?[0-9]*)',
                                     text, flags=re.IGNORECASE):
                try:
                    found.append(float(match.group(1)))
                except ValueError:
                    continue
        return found

    def close(value, expected, tol=0.20):
        if value is None or not isfinite(value):
            return None
        return abs(value - expected) / abs(expected) <= tol

    text = normalize_math_text(flatten_text(transcript))
    scores = {}

    # non_empty_answer / not_refusal 只作诊断项输出，权重已归零（见下折算处注释）
    scores["non_empty_answer"] = 0.0 if len(text.strip()) < 30 else 1.0
    scores["not_refusal"] = 0.0 if has_any(text, [
        r'无法回答', r'不能回答', r'不会做', r'i cannot', r'i can\'t', r'cannot solve'
    ]) else 1.0

    beta = extract_plain(text, [r'β', r'beta', r'无量纲壳强度'])
    scores["beta_numeric"] = 1.0 if any(
        close(v, -3.2754, 0.05) for v in beta) else 0.0

    x_val = extract_plain(text, [r'x\s*=\s*kr', r'kr'])
    scores["kR_numeric"] = 1.0 if any(close(v, 2.000, 0.05) for v in x_val) else 0.0

    # 有限厚修正：**文字/公式结论 + 数值锚同现**（照化学03 rate_limiting_diffusion 的口径）。
    # 旧版把 `1-cos`、`百分之几` 也当独立命中支，这两支在数值全错后一字不动 —— 5/5 白拿，
    # 判的是「提到过这个公式/说过这句话」而不是「算对了修正量」。
    # 数值锚全部绑在自己的标签上（qt≈0.259、1-cos(qt)≈0.033=3.3%），且都是小数，
    # 数值探针能把它们作废；裸 `0.033` 一支不许留，它会命中扰动后的无关碎片。
    ft_pos = has_any(text, [r'1\s*-\s*cos', r'百分之几', r'系统(?:性)?修正', r'传递矩阵'])
    ft_num = has_any(text, [
        r'qt\s*[:=≈约]?\s*0\.2[56]\d*',
        r'1\s*-\s*cos\s*\(?\s*(?:qt|0\.2[56]\d*)\s*\)?\s*[:=≈约]?\s*'
        r'(?:0\.03[0-9]\d*|3\.[0-9]+\s*(?:e\s*-\s*0?2|x\s*10\s*\^?\s*-\s*0?2|%))',
    ])
    scores["finite_thickness_correction"] = 1.0 if (ft_pos and ft_num) else 0.0

    # 同一个截面在不同单位下是同一个物理答案：2.60e5 nm² = 2.602e7 Å²
    # = 2.60e-13 m² = 2.60e-7 cm² = 2.60e15 barn。只认 nm² 一种写法会把
    # 「用 Å² 报结论」误判成答错。
    # 判据锚在「数值+面积单位」而不是「σ 符号后紧跟数值」：答复里 σ 与结论数值
    # 常被 \rm el、\frac{...} 或换行隔开（`σ_tot=(4π/k²)Σ…` 换行后才写 `=2.60×10^5 nm²`），
    # 按符号紧邻取值会一处都匹配不到。同时排除 /sr 尾巴，避免把 90° 微分截面
    # （1.01×10^4 nm²/sr）当成总截面。
    sigma_forms = (
        (2.60e5, r'nm'),
        (2.602e7, r'(?:å|a(?![a-z])|angstrom|埃)'),
        (2.60e-13, r'm(?![a-z])'),
        (2.60e-7, r'cm'),
        (2.60e15, r'barn'),
    )
    # 容差 0.10 而不是 0.25：0.25 宽到能把扰动后的值放回带内 —— run3 的
    # `2.6x10^-13 m^2` 在含整数档被扰成 `0.2002x10^-13`（=2.002e-13，相对差 0.23），
    # 照旧判命中。这一处伪命中会让 --mixed 整题退回保守的「仅小数」档，
    # 连带把 bound_state_count / kR_numeric 的整数结论也留在地板里。
    #
    # 同时补 `e` 记号支：原来只认 `x 10^n`，而 `σ_el ≈ 2.60e7 Å^2` 这种写法
    # （run1/run4 都这么写、结论完全正确）整族丢分 —— 与容差方向相反的假阴性，
    # 两处一起改才既压得住地板又不冤枉正确答复。
    sigma_hit = False
    sigma_pat = (r'(-?[0-9]*\.?[0-9]+)\s*'
                 r'(?:(?:x|\*)\s*10\s*\^?\{?\s*([-+]?\d+)\s*\}?|e\s*([-+]?\d+))'
                 r'\s*(?:nm|cm|m|a|å|angstrom|埃|barn)\s*\^?\{?\s*2?\s*\}?\s*(?:²)?'
                 r'([^\n]{0,6})')
    for match in re.finditer(sigma_pat, text, flags=re.IGNORECASE):
        if '/sr' in match.group(4).replace(' ', '').lower():
            continue          # 微分截面，不是总截面
        exp_group = 2 if match.group(2) is not None else 3
        value = float(match.group(1)) * (10 ** int(match.group(exp_group)))
        pos = match.end(exp_group)
        unit_text = text[pos:pos + 12].lower().lstrip(" ^{}")
        for target, unit in sigma_forms:
            if close(value, target, 0.10) and re.match(unit, unit_text):
                sigma_hit = True
                break
        if sigma_hit:
            break
    scores["sigma_tot_numeric"] = 1.0 if sigma_hit else 0.0

    # 计数结论的写法：`总空间本征态数为 4`、`空间本征态总数：1+3=4`、`共 4 个空间态`
    # 都是同一个结论；`完整单粒子态数 = 4×2 = 8` 与 `共 8 个单粒子束缚态` 同理。
    # 原判据只认一种措辞，导致 5 次答复里唯一算全的那次也被判 0。
    #
    # 0811 补：spin 支原先五条正则都要求 8 紧邻某个特定词（「共 8」要「共」字贴着、
    # 「完整单粒子…8」要「完整」二字），LaTeX 赋值式 `单粒子态 $N_{tot}=8$` 与表格式
    # `| 单粒子态总数 | 8 |` 整族丢分（space 支两种写法都过，只挂在 spin 上）。
    # 补第 6 条：态数类名词 + 邻接窗内的 8，与 space 支同构。
    space_count_ok = has_any(text, [
        r'空间(?:本征)?态(?:的)?(?:总)?数[^\n]{0,26}?(?<![\d.])4(?![\d.])',
        r'空间(?:本征)?态总数[^\n]{0,26}?(?<![\d.])4(?![\d.])',
        r'共\s*4\s*个空间',
        r'1\s*\+\s*3\s*=\s*4',
    ])
    spin_count_ok = has_any(text, [
        r'8\s*个(?:单粒子|束缚|自旋)',
        r'完整单粒子(?:束缚)?(?:态|数){0,2}[^\n]{0,26}?(?<![\d.])8(?![\d.])',
        r'(?:计入|含|加上|考虑)[^\n]{0,16}自旋[^\n]{0,32}?(?<![\d.])8(?![\d.])',
        r'4\s*(?:x|\*)\s*2\s*=\s*8',
        r'共\s*8',
        # 与 space 支同构：态数类名词 + 窗内的 8。覆盖 `单粒子态 N_tot=8`、
        # `| 单粒子态总数 | 8 |`、`束缚态数目为 8` 等赋值式/表格式写法。
        r'(?:单粒子|束缚)(?:本征)?态(?:的)?(?:总)?(?:数|数目)?[^\n]{0,26}?(?<![\d.])8(?![\d.])',
    ])
    scores["bound_state_count"] = 1.0 if (space_count_ok and spin_count_ok) else 0.0

    # 束缚态类型：第 5 类白拿项（纯文字/定性结论）。数值扰动原理上测不到它 ——
    # 「只存在 s、p 束缚态」是定性判定，改数字不改结论词，所以它会稳定留在数值地板里。
    # 不给它硬塞数值闸门（塞了就是把一条本来该由标签替换算子覆盖的判据改错），
    # 覆盖它的应当是 scripts/audit_label_swap.py + tests/fixtures/conclusion-label-pairs.json；
    # ⚠️ 该清单里目前没有本题的条目，等于这一项当前无任何算子覆盖。
    scores["bound_state_types"] = 1.0 if (
        has_any(text, [r's\s*[态波]', r'l\s*=\s*0'])
        and has_any(text, [r'p\s*[态波]', r'l\s*=\s*1'])
        and has_any(text, [r'2l\s*\+\s*1', r'β\s*<\s*-\s*\(?2l', r'阈值'])
    ) else 0.0

    scores["has_area_unit"] = 1.0 if has_any(text, [
        r'nm\s*(?:\^?2|²)', r'm\s*(?:\^?2|²)', r'barn', r'cm\s*(?:\^?2|²)'
    ]) else 0.0

    # 白拿口径收紧（照化学03 `_SCORED` 的注释）：三项权重归零，只留在返回 dict 里
    # 当诊断项输出（不删键，审计脚本与回归 fixture 要逐项对照）——
    #   · non_empty_answer / not_refusal：空答与拒答由 runner 层记 0，在 grade() 里
    #     再给一遍就是与题目无关的白拿（白拿项①）；
    #   · has_area_unit：「全文任何位置出现 nm²/m²/barn」的裸单位存在性检查，数值全错
    #     也一字不动（白拿项②③）。面积单位已经是 sigma_tot_numeric 的**邻接条件**
    #     （数值+单位一起判，见上），不再单列计权。
    # 释放出的 0.05×3=0.15 按比例回填 6 个实质项：新权重 = 旧权重/(1−0.15)，即
    #   beta 0.2353 / kR 0.1176 / finite 0.1765 / sigma 0.2353 / count 0.1765 / types 0.0588。
    # 六项全中仍是满分 1.0（0.85/0.85），真实分不因归零而下降。
    #
    # 残留说明（数值探针压不掉、但不属白拿的两类）：
    #   · kR_numeric、bound_state_count 的结论是**整数**（kR=2；空间态 4 / 含自旋 8），
    #     只扰小数的探针结构上碰不到，必须由「含整数」档覆盖 —— 这正是上面把 sigma 容差
    #     收到 0.10 的目的：不让本题再退回仅小数档。
    #   · bound_state_types 是定性结论，归标签替换算子（见该项注释）。
    _R = 1.0 - 0.15
    scores["auto_final_answer_score"] = round(
        (0.20 / _R) * scores["beta_numeric"]
        + (0.10 / _R) * scores["kR_numeric"]
        + (0.15 / _R) * scores["finite_thickness_correction"]
        + (0.20 / _R) * scores["sigma_tot_numeric"]
        + (0.15 / _R) * scores["bound_state_count"]
        + (0.05 / _R) * scores["bound_state_types"], 4)

    return scores
```

### Criterion 1: δ 壳强度反演与薄层近似判据（第1问，Weight: 20%）

**Score 1.0**: 由 `x=kR=[E*/(ħ²/(2mnR²))]^1/2=2.000` 和 p 波峰顶条件 `δ1=π/2`（对应 `tanδ1` 发散、`βJ1N1-x=0`）反演 `β=x/(J1N1)≈-3.275`，得 `λ=βħ²/(2mnR)≈-1.09×10^-34 J·m`；计算 `λthin=4π(ħ²/2mn)Δρt≈-1.087×10^-34 J·m`，按 0.2% 标准判定相对差约 0.02% 代数一致；进一步算 `Vlayer≈-339 neV`、`qR≈12.95`、`qt≈0.259`、`1-cos(qt)≈3.3%`，明确 `t/R=0.020` 不足以保证有限厚层与理想 δ 壳在共振位置高精度一致（应预期百分之几系统修正），且区分「理想 δ 壳参数层面代数一致」与「真实有限厚层复现实测峰位」。

### Criterion 2: 径向匹配、各分波相移与截断（第2问，Weight: 20%）

### Criterion 3: 总弹性截面、光学定理与 90° 微分截面（第3问，Weight: 25%）

### Criterion 4: 束缚态角动量、结合能与简并度（第4问，Weight: 35%）
