# SFT标准-response	
第0步 模型判定:废水基体存在干扰,需辨析乘性/加性效应并做线性域门控。外标斜率k_ext=0.0450 L·mg⁻¹（过原点,纯标准）反映无基体条件灵敏度；标准加入斜率取自样品自身基体,可自动校正乘性(信号抑制)效应,但不能校正加性背景。

第1步 扣加性背景:A_bg=0.030（分子吸收+试剂空白）对取样、定容一致的各溶液为恒定加和项,只平移截距不改斜率,但求x截距前必须逐点扣除。净吸光度A_net=A_meas−0.030:C_add=0→0.108；2.0→0.180；4.0→0.252；8.0→0.372。

第2步 判乘性效应:用线性区低浓度点求加入法斜率 k_add=(0.252−0.108)/(4.0−0)=0.0360 L·mg⁻¹。k_add/k_ext=0.0360/0.0450=0.80<1,存在约20%乘性抑制,故外标法系统偏低、必须采用标准加入法（自洽）。

第3步 线性动态域门控:题给线性上限为稀释后溶液总Pb=C_x+C_add≤10.0 mg·L⁻¹。粗估C_x≈3:+8点总浓度≈11>10.0,越限；数值佐证——前三点段斜率恒为0.0360,含第4点后段斜率(0.372−0.252)/4=0.030变小、出现负偏离,证实其落入饱和非线性区,必须剔除,仅用0、2.0、4.0三点。

第4步 线性拟合（三点精确共线）:A_net=0.0360·C_add+0.108。

第5步 求稀释液中样品Pb（x截距,注意零点基准）:样品Pb信号=0.0360·C_x,且0.0360·C_x+A_bg=0.138 → 0.0360·C_x=0.138−0.030=0.108 → C_x=0.108/0.0360=3.00 mg·L⁻¹（等价于扣背景后A_net=0处外推）。复核该点总浓度3.00≤10.0,位于线性区,自洽。

第6步 稀释还原:稀释倍数f=50.00/10.00=5.00 → 原废水总Pb=3.00×5.00=15.0 mg·L⁻¹。

第7步 形态一致性（排除40%EDTA干扰项）:本法为火焰AAS(283.3 nm,空气-乙炔火焰约2300 K),EDTA-Pb络合物在火焰中完全热解并原子化,络合态与游离态原子化效率一致,加入的Pb²⁺标准亦全部原子化,故测得为总Pb。'40%以EDTA络合'仅为自洽性/干扰项,火焰条件下不需按0.60上调（否则误得25.0 mg·L⁻¹）；该形态校正仅在石墨炉/溶液相形态特异方法时才需要。

结论:废水中总Pb浓度=15.0 mg·L⁻¹。

否则它就在探针的盲区里 —— 这是符号式旁路（第 6 类盲区）的整数变体。

```python
import re


def normalize(text: str) -> str:
    """统一乘号、负号、上标、空白，并展平 LaTeX 壳，便于抽取。

    展 `\\frac`/剥 `\\boxed` 是必需的：run3 的结论写成
    `\\boxed{15.0\\ \\text{mg·L}^{-1}}`，不剥壳时数值与单位之间夹着
    `\\ \\text{`，"数值+相邻单位"判据全部失配 —— 那是写法差异，不是答错。
    """
    repl = {
        "×": "x", "·": "", "−": "-", "—": "-", "﹣": "-",
        "⁰": "0", "¹": "1", "²": "2", "³": "3", "⁴": "4",
        "⁵": "5", "⁶": "6", "⁷": "7", "⁸": "8", "⁹": "9", "⁻": "-",
    }
    for k, v in repl.items():
        text = text.replace(k, v)
    for _ in range(3):
        text = re.sub(r"\\[tdc]?frac\s*\{([^{}]*)\}\s*\{([^{}]*)\}",
                      r"(\1)/(\2)", text)
    for _ in range(3):
        text = re.sub(r"\\(?:boxed|text|mathrm|mathbf|operatorname|rm|bf|it)"
                      r"\s*\{([^{}]*)\}", r"\1", text)
    text = re.sub(r"\\times|\\cdot", "x", text)
    text = re.sub(r"\^\s*\{?\s*(-?\d+)\s*\}?", r"\1", text)   # ^{-1} → -1
    text = re.sub(r"\\[,;:!]|\\ ", " ", text)                  # LaTeX 间距
    for ch in ("$", "**", "\\(", "\\)", "\\[", "\\]"):
        text = text.replace(ch, " ")
    return re.sub(r"\s+", " ", text)


_UNIT = r"(?:mg\s*/?\s*L\s*(?:-\s*1)?|mg\s*L\s*-\s*1|ppm)"
_SLOPE = r"L\s*/?\s*mg"
_CUT = r"补充|附注|注\s*[:：]|说明\s*[:：]|备注|若把|（若|\(若"
_NEG = r"(?:不|未|无需|不必|不用|无须|没有|忽略|不计)"
_SCORED = ("target_with_unit", "bg_subtracted_numeric", "kadd_numeric",
           "intercept_300", "dilution_factor_5", "linear_gate_8pt")


def _conclusion_blocks(t: str):
    """按可信度从高到低给出结论块候选（白拿项②的修法：抽取器限定在结论块内）。

    旧版 `extract_total_pb` 兜底取**全文最后一个带单位的数**，于是"复述题面 +
    拒答"里的 `8.0 mg/L` 就够它返回非 None —— `target_extracted` 与 `has_unit`
    双双命中、三条反向项全送，一份不给任何答案的答复拿 0.900。
    这里只在尾部 35%（至少 300 字符）里找，且优先从最后一个结论标签之后取。
    """
    tail = t[max(0, len(t) - max(300, int(len(t) * 0.35))):]
    out = [tail[m.end():] for m in reversed(list(re.finditer(
        r"(?:答案|答|结论|综上|最终|final\s*answer)\s*[:：]?", tail)))]
    out.append(tail)
    return out


def extract_conc(t: str):
    """在结论块内抽"数值 + 相邻浓度单位"，抽不到即 None（不做全文兜底）。

    `_SLOPE` 负向前查是必需的：斜率单位 L/mg 与浓度 mg/L 量纲互为倒数，
    不排除的话 `0.0450 L·mg-1` 会被"数值+单位"支当成浓度结论抽走。
    `_CUT` 切掉结论块里的让步性后缀（`补充：…8.0 mg/L 那点…`、
    `（若按 40% 上调则更高…）`），否则讨论用的数会被当成结论。
    """
    for blk in _conclusion_blocks(t):
        blk = re.split(_CUT, blk)[0]
        hits = [m for m in re.finditer(r"(\d+\.?\d*)\s*" + _UNIT, blk, re.I)
                if not re.search(_SLOPE, blk[max(0, m.start() - 14):m.start()],
                                 re.I)]
        if hits:
            return float(hits[-1].group(1))
    return None


def grade(answer: str) -> dict:
    """`_SCORED` 里没有 non_empty_answer / not_refusal：空答与拒答由 runner 层
    记 0，在 grade() 里再给一遍就是与题目无关的白拿（白拿项①）。
    """
    t = normalize(answer or "")
    checks = {}
    val = extract_conc(t)

    # 1. 结论数值 + 相邻单位一起判：抽不到、单位不贴着结论数值、量纲不对都是 0。
    #    不拆成 target_extracted / has_unit 两项（白拿项②③）。
    TARGET = 15.0
    checks["target_with_unit"] = (
        val is not None and abs(val - TARGET) <= TARGET * 0.05)

    # 2. 加性背景逐点扣除：只收派生量（=A_meas-0.030，算过才写得出），不收题面
    #    自带的 0.030，也不收裸 `背景` 一词 —— 「背景可忽略不扣」照样含这个词，
    #    说反话与说对话同分。否定词绑到"扣除"这个动作上，跨度内禁 `而`，避免
    #    误伤「不是忽略背景**而是**逐点扣除」这类对比句。
    #    ⚠️ 单个 0.108 不够：数值扰动后 `A_net=0.008316+0.108C_add`（原式里
    #    0.0360 被扰成 0.108）仍命中，5/5 假阳性。要求**第二个净值**（0.180 /
    #    0.252）或减法式 `0.138-0.030` 同现 —— 一次扰动不可能把两个独立派生量
    #    同时打回原值。run2 只写了首点，靠减法式那一支收。
    bg_neg = re.search(r'背景[^。；\n而]{0,8}(?:可|能)?(?:忽略|不计|无需|不必|不用)'
                       r'|背景[^。；\n而]{0,6}' + _NEG + r'(?:扣|减|除)'
                       r'|' + _NEG + r'[^。；\n而]{0,4}扣(?:除)?[^。；\n而]{0,4}背景', t)
    checks["bg_subtracted_numeric"] = bool(
        re.search(r'0\.108', t)
        and (re.search(r'0\.180', t) or re.search(r'0\.252', t)
             or re.search(r'0\.138\s*-\s*0\.030', t))) and not bg_neg

    # 3. 加入法斜率 k_add=0.0360 L·mg⁻¹：题面只给外标 0.0450，0.0360 必须自己算。
    checks["kadd_numeric"] = bool(re.search(r'0\.036(?:0(?![0-9])|(?![0-9]))', t))

    # 4. 定容液中 C_x=3.00 mg·L⁻¹（或写成 0.108/0.0360 这一步除法）。
    checks["intercept_300"] = bool(
        re.search(r'-?\s*3\.00\s*(?:' + _UNIT + r'|\)|,|，|。|$)', t, re.I)
        or re.search(r'0\.108\s*\)?\s*/\s*\(?\s*0\.036', t))

    # 5. 稀释还原因子 5：50.00/10.00 这一步换算留痕。
    #    ⚠️ 裸「稀释了 5 倍」一支已删：`5` 是整数，数值扰动只动小数，这一支
    #    对探针完全免疫（4/5 假阳性，且 run5 全篇只有这一支）。留下的两支都
    #    含小数，绕不过去：`50.00/10.00` 与 `3.00×5`。
    checks["dilution_factor_5"] = bool(
        re.search(r'50(?:\.00)?\s*\)?\s*/\s*\(?\s*10(?:\.00)?', t)
        or re.search(r'3\.00\s*x\s*5(?:\.00?)?(?![0-9])', t))

    # 6. 线性动态域门控：8.0 加标点越限须剔除。否定式只收"声称把该点纳入拟合"，
    #    不收"该点越限但不影响截距法结果"—— 后者说的是结论稳健性，不是把点收回去。
    #    正例 7/7 命中、反例 5/5 拒（含「8.0 点不剔除，四点一起拟合」）。
    gate_pos = re.search(r'(?:8\.0|\+?\s*8\s*点|第\s*4\s*点|第四点)[^。；\n]{0,48}?'
                         r'(?:超|越|出|剔|舍|弃|不宜|排除|饱和|非线性|不用于|不参与)', t)
    gate_neg = re.search(
        r'8\.0[^。；\n]{0,26}(?:不|未|无需|不必|无须)[^。；\n，,、]{0,3}(?:剔|舍|弃|排除)'
        r'|8\.0[^。；\n]{0,26}(?:仍|照样|依然|一并|全部|均|也)[^。；\n，,、]{0,5}'
        r'(?:用于|参与|纳入|计入|拟合)', t)
    checks["linear_gate_8pt"] = bool(gate_pos) and not gate_neg

    passed = sum(bool(checks[k]) for k in _SCORED)

    # 7. 三个典型陷阱改**扣分项**（白拿项④）：命中才扣，缺值不加不扣。
    #    旧写法 `val is None or abs(val-陷阱值)>阈值` 在缺值时三项全为真，
    #    于是"软托词"比老实拒答分高、答错被罚得比不答重，方向是反的。
    #    19.2 = 未扣背景；25.0 = 按 40% EDTA 上调；3.00 = 漏乘稀释倍数。
    #    3.00 的窗收到 ±0.3：它同时是正确中间量，容差放宽会误伤写了中间量
    #    但结论正确的答复（结论块定位已把结论限定在尾部，此处只防结论真写成 3.00）。
    penalty = 0.0
    for key, trap, tol in (("hit_no_bg_subtract", 19.2, 1.0),
                           ("hit_edta_correction", 25.0, 1.0),
                           ("hit_missing_dilution", 3.0, 0.3)):
        checks[key] = val is not None and abs(val - trap) <= tol
        if checks[key]:
            penalty += 0.25

    # 8. 等权折算（口径按 0811 物理题 §6：删项后不重新归一化，
    #    分母就是剩下的计分项数，扣分项在其上做减法）。
    checks["auto_final_answer_score"] = round(
        max(0.0, min(1.0, passed / len(_SCORED) - penalty)), 3)
    return checks
```
