# 构造高质量-query

某尾气计量实验测得纯¹⁴N¹⁶O(g,基态项为²Π)在300.00 K、p°=1.000 bar时S°=210.769 J·mol⁻¹·K⁻¹、Cp°=29.8537 J·mol⁻¹·K⁻¹。无电子简并的平动、转动、振动基线之和分别为199.600和29.1700 J·mol⁻¹·K⁻¹；B=1.696 cm⁻¹。仅有两个低能自旋—轨道分量。取R=8.3144626 J·mol⁻¹·K⁻¹,hc/k=1.4387769 K·cm。确定该能级方案的分裂波数及上、下分量简并度之比。

# SFT标准-response

1. 分离自旋—轨道贡献

题给S°、Cp°是总热力学量,而199.600 J·mol⁻¹·K⁻¹和29.1700 J·mol⁻¹·K⁻¹是同一温度、同一标准态下不含电子简并的平动、转动、振动基线。因此可直接相减:

S_so=210.769−199.600=11.169 J·mol⁻¹·K⁻¹,
Cp,so=29.8537−29.1700=0.6837 J·mol⁻¹·K⁻¹。

无量纲化得

s=S_so/R=11.169/8.3144626=1.34332,
c=Cp,so/R=0.6837/8.3144626=0.08223。

这里各量均处于相同的300.00 K、p°=1.000 bar基准；题目按纯理想气体统计热力学处理,不需要另作逸度修正。

2. 检查转动与电子部分能否分离

转动特征温度为

θ_rot=(hc/k)B=(1.4387769 K·cm)(1.696 cm⁻¹)=2.4402 K。

于是

θ_rot/T=2.4402/300.00=8.13×10⁻³≪1。

因此两个Ω分量的转动梯级均处于高温区,其转动配分函数之比可在本题精度下取1,公共转动贡献已包括在给定基线内。低温时则不能这样处理,必须分别从J=|Ω|逐项求和。

¹⁴N¹⁶O是异核双原子分子,转动对称数σ=1,不存在由两个相同核交换造成的奇偶J删选。转动态的2J+1简并已经属于转动配分函数,不能再计入电子简并度。

3. 确定电子分量及其简并

基态为²Π,故Λ=1、S=1/2,两个自旋—轨道分量为Ω=1/2和Ω=3/2。NO的该π电子壳层属于未过半充满情形,按Hund第三定则,较小的Ω在下:

²Π₁/₂为下分量,²Π₃/₂为上分量。

忽略更小的Λ双重分裂及外场分裂时,每个Ω分量都有±Ω二重性,因此下分量的电子简并度g₀=2。令上、下分量简并度之比为

r=g₁/g₀。

4. 建立二能级配分函数

以下分量为能量零点,上分量的摩尔能量间隔为Δ_m。定义

x=Δ_m/(RT)=hcṽ/(kT),

其中ṽ为分裂波数。电子配分函数为

q_so=g₀(1+re^(−x))=2(1+re^(−x))。

令上分量的平衡占比为

p=re^(−x)/(1+re^(−x))。

则

S_so/R=ln q_so+px
       =ln2−ln(1−p)+px,

Cp,so/R=x²p(1−p)。

电子激发不涉及体积功,所以这里电子部分的Cp与Cv贡献相同。

5. 由熵和热容反演p与x

扣除下分量的固有二重简并熵:

A=s−ln2
 =1.34332−0.693147
 =0.65017。

因此

0.65017=−ln(1−p)+px,
0.08223=x²p(1−p)。

由第二式取正根:

x=[0.08223/{p(1−p)}]^(1/2)。

代入第一式数值求解,得到

p≈0.35447,
x≈0.59947。

检验:

x²p(1−p)≈0.082230,

乘以R后为0.6837 J·mol⁻¹·K⁻¹,与实验残差一致。

6. 求简并度比

由

p/(1−p)=re^(−x)

可得

r=[p/(1−p)]e^x
 ≈[0.35447/0.64553]e^0.59947
 ≈1.000。

所以

g上/g下=1,

且由于每个分量均有±Ω二重性,可写为

g(²Π₃/₂):g(²Π₁/₂)=2:2。

7. 求分裂波数

由x=hcṽ/(kT),

ṽ=xT/(hc/k)
  =(0.59947)(300.00)/(1.4387769)
  =124.996 cm⁻¹。

按题给精度:

ṽ=125.0 cm⁻¹。

相应的摩尔能量间隔为

Δ_m=RTx
=(8.3144626)(300.00)(0.59947)
≈1.495×10³ J·mol⁻¹
=1.495 kJ·mol⁻¹。

故最终能级方案是²Π₁/₂在下、²Π₃/₂在上,分裂为125.0 cm⁻¹,上、下分量简并度之比为1.000,即2∶2。

        (in_win(0.35400, 0.35500) or in_win(0.64500, 0.64610))   # p 或 1-p
        and in_win(0.59900, 0.59990)                              # x
        or in_win(0.64980, 0.65060) and in_win(0.59900, 0.59990)  # A 与 x
    ) else 0.0

    # ---- 5. 转动—电子因子化：数值 + 高温论证 + 异核/σ=1 ----
    #    数值锚取 T/θ_rot=122.94 或 θ_rot/T=8.13e-3（两步运算）；θ_rot=2.4402
    #    只是一次乘法（A2.5），仅作补充支，且必须与语义同时到位。

               or in_win(2.4395, 2.4410))
    rot_sem = has_any(text, [
        r'高温|经典极限|θ\s*_?\s*rot\s*/\s*t\s*[≪<]|t\s*[≫>]\s*θ|因子化|可(?:以)?分离|'
        r'相消|共同(?:的)?转动',
    ])
    rot_hetero = has_any(text, [
        r'异核|heteronuclear|σ\s*[=≈]\s*1|对称数\s*(?:为|=)?\s*1',
    ])
    scores["rot_factorization"] = 1.0 if (
        rot_num and rot_sem and rot_hetero
    ) else 0.0

    # ---- 6. 其它派生中间量（追加证据，任一即可）----
    scores["derived_intermediate"] = 1.0 if (
        in_win(11.1685, 11.1695)      # S_so=11.169
        or in_win(0.68365, 0.68375)   # Cp,so=0.6837
        or in_win(1.34325, 1.34340)   # s=1.34332
        or in_win(0.082225, 0.082240)  # c=0.08223

    ) else 0.0

        "target_splitting_wavenumber": 0.26,
        "target_degeneracy_ratio": 0.24,
        "lower_component_pi_half": 0.16,
        "two_level_solution": 0.16,
        "rot_factorization": 0.10,
        "derived_intermediate": 0.08,
    }

    # ---- 陷阱：命中才扣，缺值不加不扣（A2.1 白拿项④）----
    #    错 A：漏掉 g₀=2 的 ±Ω 二重性 → ṽ=123.360、r=2.9830、p=0.62276。
    #    r 窗收到 2.975~2.992（不是 2.96~3.01）：避免与"约 3 倍"这类整数写法相撞。
    scores["hit_missing_pm_omega"] = 1.0 if (
        in_win(123.30, 123.42) or in_win(2.975, 2.992)
        or in_win(0.62220, 0.62340)
    ) else 0.0

    #    错 B/B′：把 2J+1 当电子简并（预设 r=2）→ ṽ=426.615 或 119.795、x=2.046。
    scores["hit_preset_r2"] = 1.0 if (
        in_win(426.40, 426.80) or in_win(119.70, 119.90)
        or in_win(2.0400, 2.0520)
    ) else 0.0

    #    错 C/D/E/F/G：被舍的第二根与四种换算/基准错。
    #    ⚠️ 以「ṽ 未落窗」为门：比标准答案更周全的答复可能显式写出第二根 1275.14
    #    再排除掉，不加门会反扣它（A2.4 "错误终值 ≈ 正确附加量"）。
    scores["hit_conversion_or_root"] = 1.0 if (
        (in_win(1274.90, 1275.40) or in_win(6.110, 6.121)
         or in_win(258.60, 258.90) or in_win(0.41600, 0.41720)
         or in_win(105.90, 106.20) or in_win(124.15, 124.30))
        and scores["target_splitting_wavenumber"] == 0.0
    ) else 0.0

    #    归属说反：²Π₃/₂ 在下。
    scores["hit_pi_three_half_lower"] = 1.0 if assign_negated else 0.0

    penalty = 0.25 * (scores["hit_missing_pm_omega"] + scores["hit_preset_r2"]
                      + scores["hit_conversion_or_root"]
                      + scores["hit_pi_three_half_lower"])

    # ---- 零权重追溯字段 ----
    scores["trace_2j1_not_electronic"] = 1.0 if has_any(text, [
        r'2\s*j\s*\+\s*1[^。；\n]{0,30}(?:转动|rotational)',
        r'(?:转动|rotational)[^。；\n]{0,20}2\s*j\s*\+\s*1',
    ]) else 0.0
    scores["trace_no_limit_applies"] = 1.0 if has_any(text, [
        r'(?:基态近似|完全高温|高温极限|两个极限)[^。；\n]{0,20}(?:' + _NEG + r')',
        r'(?:' + _NEG + r')[^。；\n]{0,12}(?:适用|成立)[^。；\n]{0,10}(?:极限|近似)',
    ]) else 0.0

    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)
    return scores
