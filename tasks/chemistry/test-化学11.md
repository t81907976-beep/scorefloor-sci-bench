# 构造高质量-query

烟气原位仪用18797 cm⁻¹激光校准CO₂偏振拉曼。全积分数据“同位素:ν₋/ν₊(cm⁻¹),I₊/I₋”为¹²C¹⁶O₂:1286/1382,2.2011；¹³C¹⁶O₂:1268/1368,4.2730；¹²C¹⁸O₂:1225/1325,1.2209。I∝N₀(18797−ν)⁴|M|²；V与r=M₂ν₂/Mν₁同位素不变,标定|r|<0.5。求¹²C¹⁶O₂两零级带心和|V|。

# SFT标准-response

1. 确定二能级空间

线性CO₂属于D∞h点群。ν₁对称伸缩态的振动对称性为Σg⁺。弯曲振动ν₂为Πu,而两个弯曲量子的对称化直积包含

[Πu⊗Πu]sym=Σg⁺⊕Δg。

因此v₂=2中只有l=0的Σg⁺分量与ν₁同对称,能够发生Fermi耦合；l=±2的Δg分量不能进入本题的二能级矩阵。两个相关态均为g态,在这里通过拉曼跃迁观察。

2. 二能级哈密顿量

取|1⟩=|ν₁⟩、|2⟩=|2ν₂,l=0⟩,写

H=[[E₁⁰,V],[V,E₂⁰]]。

令d=E₂⁰−E₁⁰,则观测分裂满足

D=ν₊−ν₋=√(d²+4V²),

且由迹不变性

(E₁⁰+E₂⁰)/2=(ν₊+ν₋)/2。

三个同位素体的观测分裂为

D₁=1382−1286=96 cm⁻¹,
D₂=1368−1268=100 cm⁻¹,
D₃=1325−1225=100 cm⁻¹。

3. 校正拉曼散射频率的四次方因子

斯托克斯散射光波数为νs=18797−ν。对同一同位素体,两带具有共同下态,N₀在比值中消去,因此真正的跃迁矩平方比为

R=|M₊|²/|M₋|²=(I₊/I₋)[(18797−ν₋)/(18797−ν₊)]⁴。

代入数据得到

R₁=2.2011(17511/17415)⁴≈2.2500,
R₂=4.2730(17529/17429)⁴≈4.3719,
R₃=1.2209(17572/17472)⁴≈1.2491。

定义强度不对称度

Y=(R−1)/(R+1),

则

Y₁≈0.384615,Y₂≈0.62769,Y₃≈0.11077。

4. 联立强度与能级分裂求V

选择零级基态相位使V>0,并定义r=M2ν₂/Mν₁。由二能级本征矢的相干叠加可得

Y=[(r²−1)d+4rV]/[(1+r²)D]。

令

A=(r²−1)/(r²+1),C=2r/(r²+1),

则A²+C²=1,并有

Y=A(d/D)+C(2V/D)。

对D₂=D₃=100 cm⁻¹的两个同位素体,|d₂|=|d₃|。由于其Y值不同且|r|<0.5使A不为零,二者必须取相反的失谐符号。令

x=2V/100,
S=(Y₂+Y₃)/2≈0.36923,
T=(Y₂−Y₃)/2≈0.25846。

于是

Cx=S,
−A√(1−x²)=T。

结合A²+C²=1,有

S²/x²+T²/(1−x²)=1。

其两个数值根为

x²≈0.9216或0.1479。

第一根给出x=0.9600、A=−12/13、C=5/13,从而

r²=(1+A)/(1−A)=1/25,

即在V>0约定下r=+0.200,满足|r|<0.5；同时

|V|=100x/2=48.0 cm⁻¹。

另一根给出|r|≈0.75,不符合标定条件,故排除。

5. 反演¹²C¹⁶O₂的零级带心

对¹²C¹⁶O₂,D₁=96 cm⁻¹,而2|V|=96 cm⁻¹,因此

|d₁|=√(D₁²−4V²)=√(96²−4×48²)=0。

所以两个零级态恰好简并。它们的共同带心由迹给出:

(E₁⁰+E₂⁰)/2=(1286+1382)/2=1334 cm⁻¹。

故

Eν₁⁰=1334 cm⁻¹,
E2ν₂,l=0⁰=1334 cm⁻¹,
|V|=48.0 cm⁻¹。

这里的2ν₂零级带心是未受Fermi耦合扰动的非谐振动项值,不能把某个ν₂观测带心简单乘以2；1286 cm⁻¹和1382 cm⁻¹则是耦合后的两个本征带心。

## Grading Criteria

- [ ] 两个零级带心都给出且**相等**：`E°(ν₁)=E°(2ν₂,l=0)=1334 cm⁻¹`，并明确这来自 `|δ₁|=√(D₁²−4V²)=√(96²−4×48²)=0` 的精确简并，不是"两个带心差不多"。
- [ ] `|V|=48.0 cm⁻¹`，且是**从强度反演出来**的，不是由 `D₁=2|V|` 倒推的——后者把要证的结论当前提。
- [ ] 跃迁矩比 `r=M₂ν₂/Mν₁=+0.200`（`|r|<0.5` 分支），并说明另一根 `|r|≈0.750`（对应 `|V|≈19.2 cm⁻¹`）被标定条件排除。
- [ ] 强度比先按**散射光波数**的四次方校正：`R=(I₊/I₋)[(18797−ν₋)/(18797−ν₊)]⁴`，得 `R=2.2500 / 4.3719 / 1.2491`；不得直接用题给面积比，也不得用拉曼位移 ν 本身的四次方。
- [ ] 识别 `2ν₂` 流形中只有 `l=0` 的 Σg⁺ 分量能与 Σg⁺ 的 ν₁ 费米耦合，`|l|=2` 的 Δg 分量被对称性排除，故二能级模型成立。
- [ ] 观测分裂只给出 `D=√(δ²+4V²)`，不能直接认定 `D=2V`；三个同位素体的 `D` 分别为 96 / 100 / 100 cm⁻¹。
- [ ] 对 `D₂=D₃=100 cm⁻¹` 的两支论证其失谐**必须取相反符号**（Y 值不同而 |δ| 相同），据此建立 `S²/x²+T²/(1−x²)=1` 并解出 `x=2|V|/100=0.9600`、`A=−12/13`、`C=5/13`。
- [ ] 有闭合验证：把解回代第一个同位素体，`Y₁(pred)=C=0.38461` 与观测 `Y₁=0.38462` 一致。

```python
def grade(transcript: list, workspace_path: str, meta: dict) -> dict:
    import re

    def flatten_text(items):
        parts = []
        for item in items:
            if isinstance(item, dict):
                for key in ("content", "text", "message", "output"):
                    value = item.get(key)
                    if isinstance(value, str):
                        parts.append(value)
            elif isinstance(item, str):
                parts.append(item)
        return "\n".join(parts)

    def strip_reasoning(s):
        """剥掉推理模型的思维链，只留最终答复正文。未闭合的 <think> 之后全部丢弃，
        避免把推理里试算过的候选 r 值误判成最终答案。"""
        s = re.sub(r'<(think|thinking|reasoning)>.*?</\1>', ' ', s,
                   flags=re.IGNORECASE | re.DOTALL)
        return re.split(r'<(?:think|thinking|reasoning)>', s, flags=re.IGNORECASE)[0]

    _SUP = str.maketrans("⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻", "0123456789+-")
    _SUB = str.maketrans("₀₁₂₃₄₅₆₇₈₉₊₋", "0123456789+-")

    raw = strip_reasoning(flatten_text(transcript))
    raw = re.sub(r'[⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻]+',
                 lambda m: '^' + m.group(0).translate(_SUP), raw)
    raw = raw.translate(_SUB)
    for a, b in (("−", "-"), ("—", "-"), ("﹣", "-"), ("–", "-"), ("－", "-"),
                 ("×", "x"), ("·", "*"), ("∙", "*"), ("⋅", "*"),
                 ("≅", "≈"), ("≃", "≈"), ("∼", "~")):
        raw = raw.replace(a, b)
    raw = re.sub(r'\\(?:approx|simeq|sim|cong)', '≈', raw)
    raw = re.sub(r'\\times|\\cdot', 'x', raw)
    raw = re.sub(r'\\[tdc]?frac\s*\{([^{}]*)\}\s*\{([^{}]*)\}', r'(\1)/(\2)', raw)
    for _ in range(3):
        raw = re.sub(r'\\(?:boxed|text|mathrm|mathbf|operatorname|rm|bf|it)'
                     r'\s*\{([^{}]*)\}', r'\1', raw)
    raw = re.sub(r'\\[,;:!]|\\ ', ' ', raw)
    for ch in ("$", "\\(", "\\)", "\\[", "\\]"):
        raw = raw.replace(ch, " ")
    raw = raw.replace("**", " ")
    text = raw.lower()

    def numbers(s):
        vals = []
        for m in re.finditer(
                r'(?<![\d.eE^])([+-]?\d{1,7}(?:\.\d+)?)'
                r'(?![\d.]*\s*(?:\^|x\s*10|e[+-]?\d))', s):
            try:
                vals.append(float(m.group(1)))
            except ValueError:
                pass
        return vals

    nums = numbers(text)

    def in_win(lo, hi):
        return any(lo <= v <= hi for v in nums)

    def has_any(t, patterns):
        return any(re.search(p, t, flags=re.IGNORECASE) for p in patterns)

    def near(pat_val, pat_ctx, ahead=70, behind=60):
        """数值必须与语义标记邻接：pat_val 命中处前 behind / 后 ahead 字符内
        出现 pat_ctx。用于把量纲/符号做成结论数值的**邻接条件**，而不是
        全文存在性（A2.1 白拿项③）。"""
        for m in re.finditer(pat_val, text):
            seg = text[max(0, m.start() - behind):m.end() + ahead]
            if re.search(pat_ctx, seg, re.IGNORECASE):
                return True
        return False

    def val_near(pat_tok, lo, hi, ahead=40, behind=25):
        """与 near() 方向相反：先找语义标记，再在它的邻接窗里按**数值区间**判定。

        对结论数值一律用这个方向，不要用正则去描述数值本身——`0\\.201` 这类写法
        的正则窗永远漏尾随零（`0.2010` 与 `0.201` 是同一个数），
        而按区间取数不受写法影响。"""
        for m in re.finditer(pat_tok, text, flags=re.IGNORECASE):
            seg = text[max(0, m.start() - behind):m.end() + ahead]
            if any(lo <= v <= hi for v in numbers(seg)):
                return True
        return False

    scores = {}

    # ---- 1. 两个零级带心：必须都是 1334 且被写成相等/简并 ----
    #    1334 本身是 (1286+1382)/2，一步四则运算即得（A2.5 禁止单独当锚），
    #    因此把「两个零级态相等/简并」变成 1334 的邻接条件：要求 1334 附近
    #    同时出现零级语义与（相等 | 简并 | 两者都是 | δ=0）之一。
    _C = r'(?<![\d.])1334(?:\.0+)?(?![\d])'
    _ZERO_ORDER = r'零级|未扰|非谐|unperturbed|zero[- ]?order|deperturbed|e\s*\^?\s*0|带心'
    _DEGEN = (r'相等|均为|都是|两者.{0,6}(?:相同|一致|等于)|简并|degenerat|'
              r'恰好.{0,4}(?:重合|相同)|coincide|δ\s*1?\s*[=≈]\s*0|d\s*1?\s*[=≈]\s*0|'
              r'失谐.{0,6}(?:为\s*)?0')
    scores["target_center_degenerate"] = 1.0 if (
        near(_C, _ZERO_ORDER, ahead=110, behind=90)
        and near(_C, _DEGEN, ahead=160, behind=140)
        # 两个 1334 都写出来（ν₁ 与 2ν₂ 各一次）也算作"相等"的等价证据
        or len(re.findall(_C, text)) >= 2 and near(_C, _ZERO_ORDER, 110, 90)
    ) else 0.0

    #    ⚠️ 语义标记的左界一律用 `(?<![a-z0-9])` 而不是 `\b`：中文字符在 Python
    #    re 里算单词字符，`约定下r=+0.200` 的 `r` 前面**没有** \b，用 \b 会让
    #    「中文紧邻符号」这种最常见的中文答复写法整片漏掉（本题实测踩过）。
    _LB = r'(?<![a-z0-9])'

    # ---- 2. r=+0.200：本题的主鉴别器，窗收到 ±0.5% ----
    #    要求 r 语义邻接（r / 跃迁矩比 / m2ν2），避免把 0.20 这种常见数值
    #    从别处（退偏比、权重）误收。方向用 val_near：先锚符号、再按区间取数，
    #    避免用正则描述小数写法时漏掉尾随零。
    _R_TOK = (_LB + r'r\s*[=≈+]|跃迁矩\s*(?:之)?比|矩阵元\s*(?:之)?比|m\s*2\s*ν|'
              r'ratio[^。\n]{0,12}(?:moment|matrix)')
    scores["target_r_ratio"] = 1.0 if val_near(
        _R_TOK, 0.1985, 0.2010, ahead=40, behind=30) else 0.0

    # ---- 3. |V|=48.0 cm^-1 + 相邻量纲 ----
    #    单独 48.0 在所有 ν⁴ 分支里都成立，故只给低权重；量纲须贴数值。
    _UNIT = r'cm\s*\^?\s*-\s*1|cm\s*-\s*1|波数|wavenumber|1\s*/\s*cm'
    _V_TOK = (r'\|\s*v\s*\||' + _LB + r'v\s*[=≈]|耦合(?:常数|矩阵元|强度)?|'
              r'coupling|费米|fermi')
    scores["target_V_with_unit"] = 1.0 if (
        val_near(_V_TOK, 47.90, 48.10, ahead=40, behind=25)
        and near(r'(?<![\d.])4[78]\.\d+(?![\d])|(?<![\d.])48(?![\d.])', _UNIT,
                 ahead=24, behind=40)
    ) else 0.0

    # ---- 4. 校正后的强度比 R：至少两个落窗 ----
    #    这是"算过 ν⁴ 校正才写得出"的派生量。三个都收会对只报两位的答复
    #    造成假阴性，故取「至少两个」。窗宽 ±0.3% 与错 A/B/C/D 的 R 全部互斥。
    _R_HITS = sum(1 for lo, hi in ((2.2432, 2.2568), (4.3588, 4.3850),
                                   (1.2454, 1.2529)) if in_win(lo, hi))
    scores["corrected_intensity_ratio"] = 1.0 if _R_HITS >= 2 else 0.0

    # ---- 5. 强度不对称度 Y 或二次型中间量：需多步代入才写得出 ----
    #    Y=(R-1)/(R+1) 或 x=0.9600 / A=-12/13=-0.9231 / C=5/13=0.3846。
    #    这几个量必须先做完 ν⁴ 校正再做一次分式变换，一步四则运算得不到。
    scores["derived_intermediate"] = 1.0 if (
        in_win(0.6270, 0.6284)      # Y2=0.627693
        or in_win(0.11065, 0.11086)  # Y3=0.110752
        or in_win(0.36915, 0.36930)  # S=0.369223
        or in_win(0.25840, 0.25855)  # T=0.258470
        or in_win(0.92300, 0.92318)  # |A|=12/13
        or in_win(0.95990, 0.96010)  # x=0.9600
    ) else 0.0

    # ---- 6. 对称性判据：l=0 的 Σg+ 支入模型、|l|=2 的 Δg 支排除 ----
    #    纯文字结论，按 A2.1 第 5 类必须配数值锚 + 否定否决。
    #    数值锚 = 已完成 ν⁴ 校正（corrected_intensity_ratio），
    #    因为只有真的把这道题按二能级模型算下来才会产出那组 R。
    _NEG = r'不|未|非|无|没有|并不|而不|不是|无需|不必|忽略|排除|not|without|no\b'
    sym_positive = has_any(text, [
        r'l\s*=\s*0[^。；\n]{0,30}(?:σ\s*g|sigma\s*g|同(?:一)?对称|耦合|fermi|费米)',
        r'(?:σ\s*g|sigma\s*g)\s*\+?[^。；\n]{0,30}l\s*=\s*0',
        r'l\s*=\s*(?:±\s*)?2[^。；\n]{0,24}(?:δ\s*g|delta\s*g)[^。；\n]{0,24}'
        r'(?:' + _NEG + r')',
        r'(?:' + _NEG + r')[^。；\n而]{0,14}(?:δ\s*g|delta\s*g|\|?l\|?\s*=\s*(?:±\s*)?2)'
        r'[^。；\n而]{0,14}(?:耦合|参与|进入|混合|couple|mix)',
    ])
    # 否决：声称 |l|=2 的 Δg 分量参与耦合，或声称 l=0 不能耦合。
    # ⚠️ 跨度里必须**禁掉否定词**（`[^…不未非无]`）：正确答复写的正是
    # 「|l|=2 的 Δg 分量**不**参与费米耦合」，第一版否决式没排除否定词，
    # 被这句无辜句触发，把满分答复的 symmetry_two_level 判成 0（A2.3 的坑）。
    _NOSTOP = r'[^。；\n而不未非无没]'
    sym_negated = has_any(text, [
        r'(?:δ\s*g|delta\s*g|\|?l\|?\s*=\s*(?:±\s*)?2)' + _NOSTOP + r'{0,16}'
        r'(?:也|同样|一起)?' + _NOSTOP + r'{0,6}(?:参与|进入|发生)' + _NOSTOP + r'{0,4}'
        r'(?:费米|fermi|耦合|couple)',
        r'l\s*=\s*0[^。；\n而]{0,10}(?:' + _NEG + r')[^。；\n而]{0,8}'
        r'(?:耦合|参与|进入|couple)',
        r'三\s*(?:能|态)级|three[- ]?(?:level|state)\s*(?:model|模型)',
    ])
    scores["symmetry_two_level"] = 1.0 if (
        sym_positive and not sym_negated
        and scores["corrected_intensity_ratio"] == 1.0
    ) else 0.0

    # ---- 7. D²=δ²+4V²（不能认定 D=2V）：数值锚 = |δ₁|=0 已由第 1 项承担，
    #        这里收公式本身与 96/100 两个 D 值的正确使用。
    scores["splitting_relation"] = 1.0 if (
        has_any(text, [
            r'd\s*\^?\s*2\s*=\s*[^。\n]{0,20}(?:δ|d)\s*\^?\s*2\s*\+\s*4\s*v',
            r'√\s*\(?\s*(?:δ|d)\s*\^?\s*2\s*\+\s*4\s*v\s*\^?\s*2',
            r'sqrt\s*\(\s*(?:δ|d|delta)[^)]{0,12}\+\s*4[^)]{0,8}v',
            r'(?:δ|d|delta)\s*\^?\s*2\s*\+\s*4\s*v\s*\^?\s*2',
        ])
        and in_win(95.99, 96.01) and in_win(99.99, 100.01)
    ) else 0.0

    _WEIGHTS = {
        "target_center_degenerate": 0.24,
        "target_r_ratio": 0.24,
        "target_V_with_unit": 0.12,
        "corrected_intensity_ratio": 0.16,
        "derived_intermediate": 0.10,
        "symmetry_two_level": 0.08,
        "splitting_relation": 0.06,
    }
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 陷阱：命中才扣，缺值不加不扣（A2.1 白拿项④）----
    #    错 A/B/C/D：ν⁴ 校正做错 → r 落在这四段之一。四段与 target_r_ratio
    #    的接受窗 0.1985~0.2010 完全不重叠。
    scores["hit_nu4_misapplied"] = 1.0 if (
        (in_win(0.1215, 0.1237) or in_win(0.1885, 0.1905)
         or in_win(0.1938, 0.1958) or in_win(0.1966, 0.1980))
        and scores["target_r_ratio"] == 0.0
    ) else 0.0

    #    舍弃根：取 |r|≈0.75 那一支 → |V|≈19.2 cm^-1，δ₁≈88 cm^-1（带心不再简并）。
    scores["hit_wrong_root"] = 1.0 if (
        (in_win(19.15, 19.31) or in_win(0.7480, 0.7520))
        and scores["target_r_ratio"] == 0.0
    ) else 0.0

    #    把 D₁=2|V| 当作前提（而非结论）：只报 48 与 1334 却给不出 r，
    #    等于把要证的简并当已知。识别方式：|V| 落窗但 r 与校正后 R 都缺。
    scores["hit_assumed_resonance"] = 1.0 if (
        in_win(47.90, 48.10)
        and scores["target_r_ratio"] == 0.0
        and scores["corrected_intensity_ratio"] == 0.0
    ) else 0.0

    penalty = 0.25 * (scores["hit_nu4_misapplied"] + scores["hit_wrong_root"]
                      + scores["hit_assumed_resonance"])

    # ---- 以下零权重，仅供追溯（fixture 覆盖率待观测，A2.5 末段）----
    scores["trace_rejected_root"] = 1.0 if in_win(0.7480, 0.7520) else 0.0
    scores["trace_mixing_angle_45"] = 1.0 if has_any(text, [
        r'45\s*(?:°|度|deg)', r'混合角[^。\n]{0,10}45', r'θ\s*=\s*45',
    ]) else 0.0

    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)
    return scores
```
