# 构造高质量-query

某厂需要鉴别两批标称为Ln₂O₃的样品A和B。每摩尔Ln₂O₃式量含2 mol镧系离子位点。样品的原始摩尔磁化率满足χraw=χpara+χdia。测得每摩尔式量的原始χMT数据如下:A批在10、50、150、300 K时分别为0.1804、0.2716、0.5888、1.2826 cm³·K·mol⁻¹(式量)；B批在10、50、150、300 K时分别为0.1915、0.2431、0.3722、0.5874 cm³·K·mol⁻¹(式量)。抗磁磁化率分别为χdia(A)=−1.20×10⁻⁴ cm³·mol⁻¹(式量)、χdia(B)=−1.10×10⁻⁴ cm³·mol⁻¹(式量)。

候选主离子为Sm³⁺和Eu³⁺。Sm³⁺的电子组态为4f⁵,L=5、S=5/2,最低三组能量依次为0、1050、2200 cm⁻¹,简并度依次为6、8、10；Eu³⁺的电子组态为4f⁶,L=3、S=3,最低三组能量依次为0、370、1040 cm⁻¹,简并度依次为1、3、5。在本题采用的10～300 K有效磁学模型中,以上三组能级构成热布居计算所保留的能级集合；所有未列能级造成的χT残余温度依赖均小于5.0×10⁻⁵ cm³·K·mol⁻¹(Ln),可在给定数据精度下忽略。除这些能级的对角Curie热布居贡献外,每种主离子还允许存在一个待由实验数据拟合的、在10～300 K内视为温度无关的有效Van Vleck背景χVV；其数值不能仅由所列能量和简并度独立计算。χVV按每摩尔总Ln位点归一,括号中的Eu或Sm仅标记其所属主相。

A批在2 K、7～14 T范围内的高场磁化曲线满足M(H)=Msat+χlinH。实验定义的高场外推截距Msat是扣除主相线性磁化后已饱和顺磁组分的磁矩；在该温度和磁场范围内,Gd³⁺杂质磁矩可视为完全饱和,未饱和误差小于0.1%。测得Msat=0.140 μB·式量⁻¹,且磁化曲线无滞后。

已知Landé因子gJ=1+[J(J+1)+S(S+1)−L(L+1)]/[2J(J+1)],自由离子磁矩μJ=gJ√[J(J+1)]μB,hc/k=1.4388 K·cm；纯Curie体系有μeff=2.828√(χMT),其中χMT按每摩尔磁性离子计。Gd³⁺的有效磁矩为7.94 μB,饱和磁矩为7.00 μB。杂质含量以Gd³⁺占全部Ln位点的摩尔分数表示。

现有四份验收报告:甲认为A为Eu₂O₃且含1.00 mol% Gd³⁺,χVV=1.20×10⁻³ cm³·mol⁻¹(Ln,Eu主相),B为Sm₂O₃,χVV=7.00×10⁻⁴ cm³·mol⁻¹(Ln,Sm主相),且两批样品的300 K表观磁矩均不能作为基态自由离子矩；乙认为A为无杂质Eu₂O₃,低温尾部源于交换作用；丙认为A为Sm₂O₃、B为Eu₂O₃；丁认为A含2.00 mol% Gd³⁺,且两批样品的300 K数据均可直接用基态gJ公式验收。哪份报告正确？

# SFT标准-response

1. 确定基态角动量和自由离子矩

Sm³⁺为4f⁵,Eu³⁺为4f⁶,均少于半充满4f⁷,因此Hund第三定则给出J=|L−S|。

Sm³⁺:
J=|5−5/2|=5/2,
gJ=1+[J(J+1)+S(S+1)−L(L+1)]/[2J(J+1)]=2/7,
所以基态自由离子矩为
μSm,0=(2/7)√[(5/2)(7/2)]μB=0.845 μB。

Eu³⁺:
J=|3−3|=0,基态对角磁矩为0。J=0时Landé公式形式上为0/0,不能机械代入。

2. 抗磁校正并换算到每摩尔总Ln位点

由χraw=χpara+χdia,且每摩尔Ln₂O₃式量含2 mol Ln位点,故
Y(T)=(χparaT)Ln=[(χrawT)−χdiaT]/2。

A批校正结果为:
Y_A(10)=0.09080,
Y_A(50)=0.13880,
Y_A(150)=0.30340,
Y_A(300)=0.65930 cm³·K·mol⁻¹(Ln)。

B批校正结果为:
Y_B(10)=0.09630,
Y_B(50)=0.12430,
Y_B(150)=0.19435,
Y_B(300)=0.31020 cm³·K·mol⁻¹(Ln)。

由于χdia为负,校正时数值上应加上|χdia|T；除以2是由每式量含两个Ln位点决定的。

3. 计算多重态热布居的对角Curie项

对能量为EJ（cm⁻¹）的多重态,Boltzmann因子为
exp[−(1.4388EJ)/T]。

各多重态的Curie常数为
CJ=gJ²J(J+1)/8,
热布居平均为
D(T)={ΣJ(2J+1)e^(−1.4388EJ/T)CJ}/{ΣJ(2J+1)e^(−1.4388EJ/T)}。

Eu³⁺的三组能级简并度1、3、5对应J=0、1、2。对J>0,因为L=S=3,有gJ=3/2。因此
C0=0,C1=0.5625,C2=1.6875 cm³·K·mol⁻¹。
由0、370、1040 cm⁻¹三组能级得到
D_Eu(10)≈0,
D_Eu(50)≈4.0×10⁻⁵,
D_Eu(150)≈0.0450,
D_Eu(300)≈0.2228 cm³·K·mol⁻¹(Ln)。

Sm³⁺的简并度6、8、10对应J=5/2、7/2、9/2。由Landé公式得到
C5/2=0.089286,
C7/2≈1.3413,
C9/2≈3.5467 cm³·K·mol⁻¹。
由0、1050、2200 cm⁻¹三组能级得到
D_Sm(10)≈0.089286,
D_Sm(50)≈0.089286,
D_Sm(150)≈0.089356,
D_Sm(300)≈0.1002 cm³·K·mol⁻¹(Ln)。

4. 由A批高场饱和截距确定Gd³⁺含量

设Gd³⁺占全部Ln位点的摩尔分数为x。每摩尔式量有2 mol Ln位点,Gd³⁺饱和磁矩为7.00 μB,因此
0.140=2x×7.00,
解得
x=0.0100=1.00 mol%。

若含量为2.00 mol%,应产生0.280 μB·式量⁻¹的截距,与实测0.140不符,故丁报告的2.00 mol%错误。

Gd³⁺的Curie常数为
C_Gd≈7.94²/8=7.880 cm³·K·mol⁻¹(Gd)。
所以1.00 mol% Gd³⁺对每摩尔总Ln位点的χT贡献约为
xC_Gd=0.07880 cm³·K·mol⁻¹(Ln)。

5. 拟合A批

A批若为Eu主相,其模型必须满足Ln位点守恒:
Y_A(T)=xC_Gd+(1−x)D_Eu(T)+χVV(A)T。

这里Eu热布居项乘以1−x=0.9900；题目已规定χVV按每摩尔总Ln位点归一,因此χVV项不再乘0.9900。

代入x=0.0100并逐点反算:
χVV(A)=[Y_A−xC_Gd−0.9900D_Eu(T)]/T,
四个温度均给出约
χVV(A)=1.20×10⁻³ cm³·mol⁻¹(Ln)。

相应模型在10、50、150、300 K分别给出约0.09080、0.13884、0.30340、0.65931 cm³·K·mol⁻¹(Ln),与实验校正值在舍入精度内一致。因此A是含1.00 mol% Gd³⁺的Eu₂O₃主相。高场饱和截距还直接否定了乙报告所称的“无杂质Eu₂O₃”。

6. 拟合B批

B批按Sm³⁺主相模型:
Y_B(T)=D_Sm(T)+χVV(B)T。

逐点计算
χVV(B)=[Y_B−D_Sm(T)]/T,
在10、50、150、300 K均得到约
χVV(B)=7.00×10⁻⁴ cm³·mol⁻¹(Ln)。

例如10 K时
χVV(B)=[0.09630−0.089286]/10≈7.01×10⁻⁴ cm³·mol⁻¹(Ln),
300 K时
χVV(B)=[0.31020−0.1002]/300≈7.00×10⁻⁴ cm³·mol⁻¹(Ln)。
故B为Sm₂O₃,而不是Eu₂O₃,丙报告错误。

7. 判断300 K表观磁矩

若形式上把全部校正后的χT当成纯Curie项,则按每摩尔总Ln位点有
μapp(A)=2.828√0.65930≈2.30 μB,
μapp(B)=2.828√0.31020≈1.58 μB。

但A的χT包含Gd³⁺杂质Curie项、Eu³⁺低激发多重态热布居和Van Vleck背景；B的χT包含Sm³⁺激发多重态热布居和Van Vleck背景。因此2.30 μB和1.58 μB都只是300 K表观值,不能分别视为Eu³⁺或Sm³⁺的基态自由离子矩。Eu³⁺基态矩为0,Sm³⁺基态自由离子矩为0.845 μB。

综上,唯一正确的验收报告是甲。

```python
                return True
        return False

    # 中文字符在 Python re 里算单词字符，`故J=` 的 J 前面没有 \b —— 左界用负向后查。
    _LB = r'(?<![a-z0-9])'
    _NEG = r'不|未|非|无|没有|并不|而不|不是|无需|不必|忽略|错误|not|without|no\b'
    _NOSTOP = r'[^。；\n而不未非无没]'

    scores = {}

    # ---- 1. 抗磁校正方向 + 除以 2（本题的数值鉴别器）----
    #    两个 Y(300) 必须同时落窗：错 A（符号反）给 0.62330/0.29370，
    #    错 B（不除 2）给 1.31860/0.62040，三支互斥。
    scores["dia_correction_per_site"] = 1.0 if (
        in_win(0.6588, 0.6598) and in_win(0.3097, 0.3107)
    ) else 0.0

    # ---- 2. 结论标号 甲（标号答案 → 属性贴标号 + 否定否决 + 数值锚，A2.6）----
    #    "甲/乙/丙/丁" 四个字任何讨论本题的答复都会写，单判出现过等于白拿。
    _OK = r'正确|成立|符合|无误|自洽|唯一(?:一份)?'
    verdict_ok = has_any(text, [
        r'甲' + _NOSTOP + r'{0,14}(?:' + _OK + r')',
        r'(?:' + _OK + r')' + _NOSTOP + r'{0,16}甲',
        r'(?:答案|结论|报告)' + _NOSTOP + r'{0,8}(?:是|为)' + _NOSTOP + r'{0,4}甲',
    ])
    verdict_negated = has_any(text, [
        r'甲[^。；\n]{0,12}(?:' + _NEG + r')[^。；\n]{0,6}(?:正确|成立|符合)',
        r'甲(?:的)?(?:报告|方案|结论)?[^。；\n]{0,8}(?:错误|有误|不成立|不可取)',
    ])
    scores["verdict_jia"] = 1.0 if (
        verdict_ok and not verdict_negated
        and scores["dia_correction_per_site"] == 1.0
    ) else 0.0

    # ---- 3. Boltzmann 热布居的 Curie 贡献：Eu 与 Sm 各要落一个数 ----
    #    需要 hc/k、简并度、Landé 三样一起代入才写得出，不是题给数的四则运算。
    eu_ok = in_win(0.2222, 0.2234) or in_win(0.04495, 0.04510)
    sm_ok = in_win(0.08920, 0.08945) or in_win(0.1000, 0.1005)
    scores["thermal_population_curie"] = 1.0 if (eu_ok and sm_ok) else 0.0

    # ---- 4. Hund 第三定则：J=|L−S| → Sm 基态矩 0.845 μB，Eu J=0 ----
    _MU = r'μ\s*b|mu\s*_?\s*b|玻尔磁子|bohr'
    mu_sm = (in_win(0.8440, 0.8465)
             and near(r'(?<![\d.])0\.84\d+(?![\d])', _MU + r'|磁矩|moment',
                      ahead=30, behind=45))
    eu_j0 = has_any(text, [
        r'eu[^。；\n]{0,30}' + _LB + r'j\s*[=≈]\s*0',
        _LB + r'j\s*[=≈]\s*0[^。；\n]{0,26}eu',
        r'eu[^。；\n]{0,24}(?:基态)?(?:对角)?磁矩[^。；\n]{0,8}(?:为|=|是)\s*0',
    ])
    scores["hund_third_rule"] = 1.0 if (mu_sm and eu_j0) else 0.0

    # ---- 5. 由高场截距反演 Gd 分数，并给出其 Curie 贡献 ----
    #    0.140=2x×7.00 的 x=0.0100 与 2.00 mol% 都写在题面里，不能当锚。
    #    ⚠️ 0.280 μB 这个反证截距也**不能**当锚：它是题给 2.00 mol% 与 7.00 的
    #    一步运算（2×0.02×7.00），A2.5 明文禁止；实测数值扰动把题面的 0.140
    #    乘 2.0 后正好落进 0.2795~0.2805，四个模型的答复在答案全错时照样白拿
    #    0.12（地板 12%）。只收 xC_Gd：要先算 C_Gd=7.94²/8 再乘 x（两步），
    #    每 Ln 位点归一得 0.0788、每式量归一得 0.1576，两种口径都收。
    scores["gd_fraction_curie"] = 1.0 if (
        in_win(0.07855, 0.07905) or in_win(0.15740, 0.15800)
    ) else 0.0

    # ---- 6. 300 K 表观矩，且明确不是基态自由离子矩 ----
    app_nums = in_win(2.288, 2.305) and in_win(1.570, 1.585)
    app_caveat = has_any(text, [
        r'表观[^。；\n]{0,40}(?:' + _NEG + r')[^。；\n]{0,20}(?:基态|自由离子)',
        r'(?:' + _NEG + r')[^。；\n]{0,14}(?:视为|作为|当作|等同|直接)'
        r'[^。；\n]{0,14}(?:基态|自由离子)',
        r'(?:基态|自由离子)(?:自由离子)?矩?[^。；\n]{0,14}(?:' + _NEG + r')'
        r'[^。；\n]{0,10}(?:等于|等同|由此|据此|读出)',
    ])
    scores["apparent_moment_caveat"] = 1.0 if (app_nums and app_caveat) else 0.0

    # ---- 7. 其它派生中间量（追加证据，任一即可）----
    scores["derived_intermediate"] = 1.0 if (
        in_win(0.09075, 0.09085)    # Y_A(10)=0.09080
        or in_win(0.13875, 0.13890)  # Y_A(50)=0.13880~0.13884
        or in_win(0.30335, 0.30345)  # Y_A(150)=0.30340
        or in_win(0.09625, 0.09635)  # Y_B(10)=0.09630
        or in_win(0.12425, 0.12435)  # Y_B(50)=0.12430
        or in_win(0.19430, 0.19440)  # Y_B(150)=0.19435
        or in_win(1.3405, 1.3420)    # C_{7/2}=1.34127
        or in_win(3.5455, 3.5480)    # C_{9/2}=3.54672
        or in_win(0.2853, 0.2861)    # gJ(Sm)=2/7=0.285714
    ) else 0.0

    _WEIGHTS = {
        "dia_correction_per_site": 0.20,
        "verdict_jia": 0.20,
        "thermal_population_curie": 0.16,
        "hund_third_rule": 0.14,
        "gd_fraction_curie": 0.12,
        "apparent_moment_caveat": 0.10,
        "derived_intermediate": 0.08,
    }
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 陷阱：命中才扣，缺值不加不扣（A2.1 白拿项④）----
    #    错 D/E/F：把乙、丙或丁判为正确。跨度里禁掉"认为"，避免复述题面的
    #    「乙认为A为无杂质Eu₂O₃」被当成裁决。
    _NOSTOP2 = r'[^。；\n而不未非无没认]'
    scores["hit_wrong_report"] = 1.0 if (
        has_any(text, [
            r'[乙丙丁]' + _NOSTOP2 + r'{0,12}(?:' + _OK + r')',
            r'(?:' + _OK + r')' + _NOSTOP2 + r'{0,10}(?:报告)?(?:是|为)?[乙丙丁]',
            r'(?:答案|结论)' + _NOSTOP2 + r'{0,8}(?:是|为)' + _NOSTOP2 + r'{0,4}[乙丙丁]',
        ])
        and scores["verdict_jia"] == 0.0
    ) else 0.0

    #    错 A：χdia 符号取反 → Y_A(300)=0.62330、Y_B(300)=0.29370。
    scores["hit_dia_sign"] = 1.0 if (
        (in_win(0.6228, 0.6238) or in_win(0.2932, 0.2942)
         or in_win(0.28495, 0.28585))
        and scores["dia_correction_per_site"] == 0.0
    ) else 0.0

    #    错 B：停在每式量、不除以 2 → Y_A(300)=1.31860、Y_B(300)=0.62040、μapp=3.247。
    scores["hit_no_site_division"] = 1.0 if (
        (in_win(1.3181, 1.3191) or in_win(0.6199, 0.6209)
         or in_win(3.243, 3.252))
        and scores["dia_correction_per_site"] == 0.0
    ) else 0.0

    #    错 C：Hund 取 J=L+S → μ(Sm)=10.6458、μ(Eu)=9.7211。
    scores["hit_hund_wrong"] = 1.0 if (
        in_win(10.60, 10.69) or in_win(9.70, 9.75)
    ) else 0.0

    penalty = 0.25 * (scores["hit_wrong_report"] + scores["hit_dia_sign"]
                      + scores["hit_no_site_division"] + scores["hit_hund_wrong"])

    # ---- 零权重追溯字段 ----
    scores["trace_chivv_flatness"] = 1.0 if has_any(text, [
        r'(?:四个温度|各温度|逐点|所有温度|全温区)[^。；\n]{0,20}'
        r'(?:恒定|一致|相同|不变|同一)',
        r'(?:恒定|温度无关|与\s*t\s*无关)[^。；\n]{0,12}χ\s*vv',
    ]) else 0.0
    scores["trace_site_conservation"] = 1.0 if has_any(text, [
        r'1\s*-\s*x|0\.99(?:00)?|位点守恒|归一化到.{0,8}ln',
    ]) else 0.0

    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)
    return scores
```
