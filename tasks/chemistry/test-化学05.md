某连续流光反应器中,(2E,4Z,6E)-辛-2,4,6-三烯在380 K恒温下经420 nm连续激光辐照,发生6π电环化闭环。已测该三烯S0→S1吸收起始位于275 nm(对应4.51 eV)。激光提供光子通量φ=1.0×10²³ photons·cm⁻²·s⁻¹(即φ=1e+23 photons·cm⁻²·s⁻¹);该三烯的双光子吸收截面δ=80 GM(1 GM=1×10⁻⁵⁰ cm⁴·s),双光子激发速率按w₂=(1/2)δφ²计,其中通量以φ=1.0×10²³ photons·cm⁻²·s⁻¹代入。热致电环化服从Arrhenius式:指前因子A=2.0×10¹³ s⁻¹(即A=20000000000000 s⁻¹),活化能Ea=105 kJ·mol⁻¹。取hc=1240 eV·nm,R=8.314 J·mol⁻¹·K⁻¹。请在比较单光子通道、双光子通道(需用光子通量φ=1.0×10²³ photons·cm⁻²·s⁻¹)与热通道后,求该体系中主导电环化产物的CIP绝对构型。
# SFT标准-response	
第1步 反应类型与选择定则:三烯6π电环化,π电子数=6=4n+2(n=1)。Woodward–Hoffmann:热态(基态HOMO=ψ₃,端基对称)→对旋(disrotatory)；光态(激发态SOMO=ψ₄,端基反号)→同旋(conrotatory)。光化学结论由激发态SOMO决定,不能沿用基态HOMO。

第2步 单光子通道(阈值判据):E_γ=hc/λ=1240/420=2.952 eV；S0→S1起始 E_S1=1240/275=4.509 eV≈4.51 eV。因 2.952 eV < 4.51 eV,420 nm单光子处于亚吸收区,线性吸收≈0,单光子共振激发被能量阈值封锁（无显著线性光热效应）。故不能凭“见光=光化学=同旋=反式”这一捷径下结论。单光子通道速率≈0。

第3步 双光子通道:两光子合能 2×2.952=5.90 eV>4.51 eV,能量上可布居S1（若主导仍给同旋/反式）。单位还原 δ=80 GM=80×10⁻⁵⁰=8.0×10⁻⁴⁹ cm⁴·s。连续激光(CW)峰值=平均,直接用题给φ=1.0×10²³ cm⁻²·s⁻¹；由于δφ²项极小(每分子激发率<<1 s⁻¹),无需P=1-exp(-Φμ2)饱和修正,题目已指定确定性速率式 w₂=(1/2)δφ²。
w₂=0.5×(8.0×10⁻⁴⁹)×(1.0×10²³)²=0.5×8.0×10⁻⁴⁹×1.0×10⁴⁶=4.0×10⁻³ s⁻¹。
量纲核验:cm⁴·s×(cm⁻²·s⁻¹)²=cm⁴·s·cm⁻⁴·s⁻²=s⁻¹ ✓。1/2为双光子事件因子。

第4步 热通道(Arrhenius,恒温380 K):RT=8.314×380=3159.3 J·mol⁻¹；Ea/RT=105000/3159.3=33.24；exp(-33.24)=3.67×10⁻¹⁵；k_th=A·exp(-Ea/RT)=2.0×10¹³×3.67×10⁻¹⁵≈7.3×10⁻² s⁻¹。

第5步 三通道比较与主导判定:单光子≈0(阈值封锁)；双光子 w₂≈4.0×10⁻³ s⁻¹；热 k_th≈7.3×10⁻² s⁻¹。k_th/w₂≈18。热对旋通道比双光子同旋通道快约一个数量级,单光子被封锁 → 热致6π电环化(对旋)主导。隐含条件来源:题面虽强调激光,但给出恒温380 K与完整Arrhenius参数,暗示热通道并行且需定量比较；E_γ<E_S1封锁单光子；灵敏度:φ需升至~4×10²³才使w₂与k_th相当,判据稳健。

第6步 立体化学与CIP归属:底物CH₃–CH=CH–CH=CH–CH=CH–CH₃即(2E,4Z,6E)-辛-2,4,6-三烯,中心C4=C5为Z便于s-cis折叠；成环发生在两端(生成5,6-二甲基环己-1,3-二烯,两新sp³碳各带一甲基)。热态对旋闭环使(2E,…,6E)两端甲基转向环同侧 → 顺式(cis)-5,6-二甲基环己-1,3-二烯。该顺式体过C5–C6中点存在内部镜面(C5↔C6、C1↔C4、C2↔C3互换),为内消旋(meso)体,两手性中心构型相反,必为一R一S。
∴主导产物=(5R,6S)-顺-5,6-二甲基环己-1,3-二烯(meso,无旋光)。

排除项:反式(5R,6R)/(5S,6S)外消旋对来自同旋闭合,仅当光化学(单/双光子经S1)主导时出现；本题单光子被阈值封锁、双光子速率比热通道低约18倍,同旋通道不主导,故反式不是主产物,此错误已排除。

```python
            t = re.sub(r"\\[tdc]?frac\s*\{([^{}]*)\}\s*\{([^{}]*)\}",
                       r"(\1)/(\2)", t)
        for _ in range(3):
            t = re.sub(
                r"\\(?:boxed|text|mathrm|mathbf|operatorname|rm|bf|it)"
                r"\s*\{([^{}]*)\}", r"\1", t)
        t = re.sub(r"\\[,;:!> ]", " ", t)
        t = t.replace("$", " ").replace("**", " ")
        t = re.sub(r"_\s*\{\s*([^{}]{0,12})\s*\}", r"_\1", t)
        return re.sub(r"[ \t]+", " ", t)

    text = normalize_math_text(strip_reasoning(flatten_text(transcript)))

    # 假设/否证从句剪枝版：四条分支陷阱标记与主导裁决只在这上面匹配。
    # 本题的词表必须比别题宽：参考解与两个正确 run 都要把四个错误分支
    # 逐条写出来再排除（参考解「排除项：反式(5R,6R)/(5S,6S)外消旋对来自
    # 同旋闭合」、run1「单光子 420 nm 激发不足以到达 S1」、run3「420 nm
    # 单光子能量不足以激发到 S1」），故要收 不足/不够/不会/无法/无需/亚吸收。
    # ⚠️ `排除(?:项)?` 后面必须容一个全/半角冒号：参考解的否证段起手就是
    # 「排除项：」，不吃掉冒号则 `排除` 与被否证的 (5R,6R) 之间隔着标点，
    # 剪不到，满分答复会被自己的排除段反扣 0.25。
    # ⚠️ 剪枝窗只能按句读断（`[^。\n；;]{0,120}`），不能再加逗号/顿号进停止集：
    # 否证从句普遍写成「反式(5R,6R)/(5S,6S)外消旋对来自同旋闭合，仅当光化学
    # 主导时出现」这种带多个逗号的长句，一旦以逗号断句，后半截的
    # 「光化学…主导」就会漏出去打 hit_photo_dominant。
    _NEG = (r'(?:若|如果|倘若|假如|不(?:能|应|是|可|得|要|作|将|用|走|足|够|会|再|属)'
            r'|并非|而非|不可|排除(?:项)?|否决|误(?:取|用|将|把|设|以|当)'
            r'|错误(?:地)?|注意|亚吸收|无(?:法|需|显著))[：:]?')
    hyp = re.sub(_NEG + r'[^。\n；;]{0,120}', ' ', text)

    def has_any(patterns, s=None):
        s = text if s is None else s
        return any(re.search(p, s, flags=re.IGNORECASE) for p in patterns)

    scores = {}

    # 1. 结论构型 + 顺式 + meso 三者**必须贴在一起**（item B 的非数值版）。
    #    旧口径把这三件事拆成 config_correct(0.45) + has_meso(0.15)
    #    + has_cis(0.10) 三个独立项，而 `顺式`/`cis` 与 `meso`/`内消旋`
    #    是任何讨论过本题的答复都会写出的词 —— 包括结论错成反式外消旋的
    #    run2/run4/run5（它们全都写过 cis / 外消旋 对照）。合并后这 0.25
    #    再也不能脱离正确构型单独得分。
    #    窗宽不对称（cis 近 60/90、meso 远 400）是实测要求：run1 写
    #    「内消旋的 cis-5,6-二甲基…」，meso 落在描述符前的上一句里；
    #    run3 写「cis-二甲基环己二烯，其 cip 构型可表示为 (5r,6s)」。
    #    (5R,6S) 与 (5S,6R) 是同一 meso 体的等价标号，均判正确。
    CIS = r'顺式|顺-|\bcis\b|cis-'
    MESO = r'meso|内消旋'
    CFG = (r'5\s*r\s*,?\s*6\s*s|5\s*s\s*,?\s*6\s*r'
           r'|6\s*s\s*,?\s*5\s*r|6\s*r\s*,?\s*5\s*s')
    config_ok = False
    for m in re.finditer(CFG, text, flags=re.IGNORECASE):
        near = text[max(0, m.start() - 60):m.end() + 90]
        wide = text[max(0, m.start() - 400):m.end() + 400]
        if (re.search(CIS, near, flags=re.IGNORECASE)
                and re.search(MESO, wide, flags=re.IGNORECASE)):
            config_ok = True
            break
    scores["config_cis_meso"] = 1.0 if config_ok else 0.0

    # 2. 三通道定量比较 + 热主导裁决，**裁决必须挂在数值锚上**。
    #    旧 dominant_thermal 是纯文本裁决（③ 类白拿），数值扰动 5/5 存活。
    #    现在要求：w₂≈4.0e-3 出现、k_th≈7.2~7.3e-2 出现且其 ±90/60 字符内
    #    有 k_th / 热 / thermal / arrhenius 语义、且 hyp 上有热主导裁决。
    #    两个锚题面都不含（w₂ 需 GM 还原 + 通量平方，k_th 需 Arrhenius 代入）。
    #    ⚠️ k_th 语义支必须容裸 `\rm`：run1 写 `k_\rm th≈ 7.3x 10^{-2}`，
    #    归一化只压带花括号的 \rm{...}，不加 `(?:\\[a-z]+\s*)?` 这一支
    #    run1 会被判 0。
    W2 = (r'(?<![\d.])4\.0\d*\s*(?:x\s*10\s*\^?\{?\s*-\s*3|e\s*-\s*0?3)'
          r'|(?<![\d.])0\.0040?(?![\d])')
    KTH = (r'(?<![\d.])7\.[23]\d*\s*(?:x\s*10\s*\^?\{?\s*-\s*2|e\s*-\s*0?2)'
           r'|(?<![\d.])0\.07[23](?![\d])')
    rate_ok = False
    if re.search(W2, text, flags=re.IGNORECASE):
        for m in re.finditer(KTH, text, flags=re.IGNORECASE):
            seg = text[max(0, m.start() - 90):m.end() + 60]
            if re.search(r'k\s*_?\s*(?:\\[a-z]+\s*)?\{?\s*th'
                         r'|热|thermal|arrhenius', seg, flags=re.IGNORECASE):
                rate_ok = True
                break
        if rate_ok:
            # ⚠️ 裁决支不能收 `基态`：标签替换算子把 `热`→`光` 后，run1/run2 的
            #    「故主导反应为基态光致 6π 电环化」仍会命中 `主导…基态` —— 一句
            #    自相矛盾的翻面文本照样拿满这 0.30，判据退化成关键词存在性。
            #    去掉 `基态` 后五个 run 全部仍由 `热` 支命中（实测 5/5），
            #    零覆盖率损失，翻面后 5/5 归零。
            rate_ok = has_any([
                r'热[^。\n；;]{0,14}(?:主导|为主|占优)',
                r'(?:主导|为主|占优)[^。\n；;]{0,10}热',
                r'k\s*_?\{?\s*th\s*\}?[^。\n]{0,10}(?:>|大于|高于|快)'
                r'[^。\n]{0,12}w',
                r'thermal[^。\n]{0,20}dominant',
            ], hyp)
    scores["rate_thermal_dominant"] = 1.0 if rate_ok else 0.0

    _WEIGHTS = {"config_cis_meso": 0.70, "rate_thermal_dominant": 0.30}
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 分支陷阱：命中即扣分（各 0.25），一律在剪掉否证从句的 hyp 上匹配 ----

    #    反式外消旋对（同旋闭合的产物）。三个错 run 用了三套编号：
    #    run2 (2R,7R)/(2S,7S) 按三烯母体编号、run4/run5 (1R,6R)/(1S,6S)
    #    按环己二烯另一种编号、参考解排除项写 (5R,6R)/(5S,6S)。
    #    旧 hit_trans_wrong 只收 5,6 号，漏掉三个错 run 里的两个。
    scores["hit_trans_racemic"] = 1.0 if has_any([
        r'5\s*r\s*,?\s*6\s*r|5\s*s\s*,?\s*6\s*s',
        r'1\s*r\s*,?\s*6\s*r|1\s*s\s*,?\s*6\s*s',
        r'2\s*r\s*,?\s*7\s*r|2\s*s\s*,?\s*7\s*s',
        r'(?:外消旋|racem)[^。\n]{0,30}(?:trans|反式)',
        r'(?:trans|反式)[^。\n]{0,30}(?:外消旋|racem)',
    ], hyp) else 0.0

    #    把热态选择定则写反成同旋（run5 原话：「6π 热电环化遵循
    #    conrotatory（同向旋转）规则」）。正确是热态对旋 / 光态同旋。
    #    ⚠️ 连接窗必须窄（12 字符、且不跨逗号顿号冒号与破折号）：run3 写
    #    「热 6π 电环化：disrotatory，异旋 / 光化学 6π 电环化：conrotatory，
    #    同旋」——正确的对照列表里，`热` 与下一行的 `conrotatory` 只隔十几个
    #    字符。宽窗（`[^。\n]{0,20}`）会把这份正确答复反扣 0.25。
    NEAR = r'[^。\n；;，,、：:\-]{0,12}'
    scores["hit_conrotatory_thermal"] = 1.0 if has_any([
        r'热(?!对旋)(?:态|条件下|反应|致|电环化)?' + NEAR + r'(?:同旋|同向旋转|conrotat)',
        r'(?:同旋|conrotat)' + NEAR + r'(?:热态|热条件|基态热|thermal)',
    ], hyp) else 0.0

    #    认为 420 nm 单光子足以激发 S1 —— 题面刻意埋的
    #    「见光=光化学=同旋=反式」捷径。E_γ=2.95 eV < E_S1=4.51 eV 封锁它。
    scores["hit_single_photon_open"] = 1.0 if has_any([
        r'单光子[^。\n]{0,16}(?:可以|足以|能够|可行|主导)',
        r'420\s*nm[^。\n]{0,12}单光子[^。\n]{0,10}(?:激发|布居|到达)\s*s',
    ], hyp) else 0.0

    #    认为光/双光子通道主导（实际 w₂=4.0e-3 比 k_th=7.3e-2 小约 18 倍）。
    scores["hit_photo_dominant"] = 1.0 if has_any([
        r'(?:双光子|光化学|光)(?:通道|途径|过程)?\s*(?:是|为|才是|通道)?\s*'
        r'(?:主导|为主|占优)',
        r'(?:two[- ]photon|photochemical)[^。\n]{0,12}dominant',
    ], hyp) else 0.0

    penalty = 0.25 * (
        scores["hit_trans_racemic"] + scores["hit_conrotatory_thermal"]
        + scores["hit_single_photon_open"] + scores["hit_photo_dominant"])

    # ---- 零权重追溯标记：记录谁真做了哪几步派生，不参与计分 ----
    #    为什么只能是追溯：Ea/RT≈33.24 与比值 18 的覆盖率只有 1~3/5；
    #    而 2.95 / 5.90 eV 是 1240/420 的直接商与它的两倍，判别力弱，
    #    且 4.51 eV **题面原样就有**（「275 nm(对应4.51 eV)」），
    #    绝不能做计分锚。
    scores["trace_w2_rate"] = 1.0 if has_any([
        r'(?<![\d.])4\.0\d*\s*(?:x\s*10\s*\^?\{?\s*-\s*3|e\s*-\s*0?3)',
        r'(?<![\d.])0\.0040?(?![\d])']) else 0.0
    scores["trace_kth_rate"] = 1.0 if has_any([
        r'(?<![\d.])7\.[23]\d*\s*(?:x\s*10\s*\^?\{?\s*-\s*2|e\s*-\s*0?2)',
        r'(?<![\d.])0\.07[23](?![\d])']) else 0.0
    scores["trace_arrhenius_exponent"] = 1.0 if has_any([
        r'(?<![\d.])33\.2[0-9]\d*(?![\d])',
        r'(?<![\d.])3\.6[6-8]\d*\s*(?:x\s*10\s*\^?\{?\s*-\s*15|e\s*-\s*15)',
    ]) else 0.0
    scores["trace_ratio_18"] = 1.0 if has_any([
        r'(?<![\d.])1[789](?![\d.])\s*(?:倍|x|倍左右)',
        r'≈\s*1[789](?![\d.])\s*\n?\s*倍']) else 0.0
    scores["trace_photon_threshold"] = 1.0 if has_any([
        r'(?<![\d.])2\.95\d*', r'(?<![\d.])5\.90?(?![\d])']) else 0.0

    # 代码侧最终答复证据分：只反映最终答案是否可自动确认。
    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)

    return scores
```

## LLM Judge Rubric

大模型评分负责**过程、概念和逻辑**，不重复评价代码已经检查过的最终构型命中。若代码侧显示最终构型错误，大模型仍应按过程质量独立评分，但不能替代最终答案硬检查。

### Criterion 1: 电环化选择定则与激发态判据（Weight: 25%）

**Score 1.0**: 明确 6π 电环化、π 电子数 6=4n+2；按 Woodward–Hoffmann 给出热态对旋、光态同旋；并强调光化学结论由激发态 SOMO=ψ₄（端基反号）决定，不能沿用基态 HOMO=ψ₃。  
**Score 0.5**: 正确判为 6π 且给出热对旋/光同旋对应，但未点明"光态用 SOMO 而非 HOMO"这一关键区分，或说明较弱。  
**Score 0.0**: 电子数或 4n+2 判据错误，或把热/光的对旋–同旋对应关系写反，或直接凭"见光即同旋"下结论。

### Criterion 2: 单光子阈值封锁与陷阱规避（Weight: 25%）

**Score 1.0**: 用 `E_γ=1240/420=2.95 eV < E_S1=1240/275=4.51 eV` 明确论证 420 nm 单光子处于亚吸收区、单光子速率≈0，并显式排除"见光=光化学=同旋=反式"的错误捷径。  
**Score 0.5**: 计算了 E_γ 与 E_S1 并意识到单光子不足以激发，但未把它上升为对"反式捷径"的排除，或阈值比较表达含糊。  
**Score 0.0**: 未做能量阈值比较，或误认为单光子可直接激发 S1 而据此走同旋/反式结论。

### Criterion 3: 双光子与热通道速率的定量比较（Weight: 30%）

**Score 1.0**: 正确算出 `w₂=(1/2)δφ²≈4.0×10⁻³ s⁻¹`（GM 单位还原、通量平方、量纲闭合）与 `k_th=A·e^(-Ea/RT)≈7.3×10⁻² s⁻¹`（Ea/RT≈33.24），并由 `k_th/w₂≈18` 明确判定热通道主导。  
**Score 0.6**: 两条速率主路径基本正确并得出热主导结论，但其中一项存在数量级/单位/指数的次要瑕疵，或比较过程略简。  
**Score 0.3**: 只定量了热通道或双光子通道之一，另一通道缺失或明显错误，主导判定证据不充分。  
**Score 0.0**: 未做定量比较即下结论，或速率计算严重错误（如未做 GM 还原、未平方通量、Arrhenius 代入错误）导致主导通道判反。

### Criterion 4: 立体化学归属与自洽性（Weight: 20%）

**Score 1.0**: 由对旋闭合 + (2E,4Z,6E) 端基取向推出两甲基同侧（顺式），并据 C5–C6 中点内镜面（C5↔C6、C1↔C4、C2↔C3 互换）论证 meso（必为一 R 一 S），给出 `(5R,6S)-顺-5,6-二甲基环己-1,3-二烯`；且能显式排除反式 (5R,6R)/(5S,6S) 外消旋对。  
**Score 0.5**: 由对旋得到顺式并给出 meso 结论，但内镜面/对称性论证不完整，或未显式排除反式外消旋对。  
**Score 0.0**: 立体化学与所判主导通道不自洽（如热对旋却给反式），或未能给出 meso/顺式的对称性依据。
