# 化学题模板

每道题一个 `.md`，放在 `tasks/chemistry/` 下。命名沿用 `test-化学<编号>.md`。
按下面的固定顺序组织；三块评分规范逐块补齐（`lib/authoring.py` 可先生成草稿再人工定稿）。

化学题评分通常关注：**反应/物理模型是否选对、界面与体相、纯物质与溶液、几何面积与
活性面积等基准是否混淆、单位与量纲换算是否留痕、是否有闭合验证。**

# 构造高质量-query

{发送给模型的完整题面。给全所有已知量、常数、单位约定与符号规定（含标准态、基准面积、

## Grading Criteria

{结果检查清单，5~8 条，每条对应标准答案的一个关键结果或推理节点。
只写"这道题最终应满足什么"，不写 Bench 总分/效率/一致性，不写代码/LLM 分工。}

- [ ] 最终答案正确：{数值 + 单位 + 基准（几何面积/ECSA、纯水/溶液标准态等）}
- [ ] {识别了题目最容易混淆的化学条件（标准态、界面 vs 体相、基准换算）}
- [ ] {选用了正确的模型/公式，未套用零偏置或稳态模板}
- [ ] {关键中间量拆对，单位/量纲自洽}
- [ ] {能回到题设数据形成闭合验证}

## Automated Checks

代码评分只检查最终答复的硬证据，不评价推导过程。
可复用 `lib/grading_utils.py`（flatten_text / has_any / normalize / compact /
extract_number / within_tol / is_refusal）。因 `grade()` 须自包含，导入不可用时把等价
逻辑内联。

### ⚠️ 五类白拿项：新题一个都不许带（0805 假阳性审计结论）

审计做法：把 100 份真实答复的**结论数值全部作废**（文字、单位、格式一字不改）后重判，
残留分数就是"假阳性地板"。实测榜单分数里 **55% 与答案对错无关**，病因集中在这五种写法。
这不是"尽量避免"，是**这五类项一个都不许出现**。

| 白拿项 | 为什么白拿 | 换成什么 |
|---|---|---|
| `non_empty_answer`、`not_refusal` | 写够 30 字、没说"我不会"就得分，**与题目无关**，任何题任何答复都拿 | 删。空答/拒答由 runner 层记 0，不在 `grade()` 里重复给分 |
| `target_extracted`（只判抽到值） | 抽到值 ≠ 值对；推导里任一中间数字都可能被当结论 | 合并成 `within_tol(v, target, rel)` 一项，抽不到即 0 |
| `has_unit`、`has_basis`（只判出现过） | 字符串出现在推导任意一处即命中，答错照给 | 单位须与**结论数值相邻**（同行、数值后 12 字符内）且量纲相容；基准须带否定否决 |
| `not_trap_*` 写成 `val is None or abs(val-陷阱值)>阈值` | 缺值 → `val is None` → 反向项全为真；方向还错位：**软托词比老实拒答分高** | 改扣分项：命中陷阱才扣，缺值不加不扣 |
| 纯文字结论型判据（"哪个通道主导""选哪支解"） | 对数值扰动免疫，探针测不出；且**说反话与说对话同分** | 配"只有真选对才写得出的派生数值"作数值锚 + 否定否决 |

**第 6 类盲区（0811 化学题发现）：符号式旁路。** 判据允许不含小数的符号写法命中时，
数值扰动永远碰不到它。实测：`h = φ/a_w … h ≈ 0.750` 把数值扰成 `h ≈ 1.5`，`has_basis`
仍为 1.0，因为 `φ/a_w` 这一支不含小数。同类还有 `h(f)`、`rh/a_w`、`1 + δ/1000`、
`r/r_std`、整数百分数。写符号支时要清楚**这一支探针测不到**，靠人工互斥窗或并联数值锚。

### 化学题反复踩过的四个具体坑

1. **别用题干自带的词当判据。** 化学02 原先用 `异相` 判面积基准，而题干问的就是
   "本征异相电子转移速率常数"——任何答复必然写出它，0.15 无条件白送。判据要收的是
   **算过才写得出的派生量**（换算后的同位素比 0.996560、面积归一后的电导 0.08384），
   不是抄题也会出现的词，也不是题面自带的观测值（`-3.44‰`、`-56.0‰`）。

2. **容差窗必须与错误分支指纹互斥，"残差为零"不是证据。** 多未知量拟合多观测时，
   错误基准分支同样能把残差压到零。必须独立复算各分支答案指纹并写进前言：

   | 分支 | δ18O_0 | f |
   |---|---:|---:|
   | 标准 `h=0.700/(1−0.100f)` | −8.003‰ | 0.2501 |
   | 错 A：`h≡0.700`（不做 a_w 修正） | −8.155‰ | 0.2546 |
   | 错 B：`h=0.700·a_w`（乘反） | −8.301‰ | 0.2589 |
   | 错 C：h 冻结后套解析幂律 | −7.888‰ | 0.2449 |

   设窗时注意：`\d*` **没有上界**（`0\.50\d*` 实际收到 0.51；**收成
   `0\.50(?:[0-5]\d*)?` 仍无界，实际上界 0.5059** —— 0811 两侧各在同一个洞上错过一次）；
   **百分数支通常比小数支松一档**（`\b2[45](?:\.\d)?\s*%` 放行 24.0~25.9%，错 A 的 25.5%
   与错 C 的 24.5% 全在里面，要收到 `25\.0\d?\s*%` 一档或整支不收）；`target_*` 的接受窗
   不许与 `hit_*` 的触发窗重叠。

   ⚠️ **裸整数百分数支一律不许加。**看似能用左界前瞻 `(?<![.\d])25\s*%` 把 `25.46%`
   挡在外面，但**错误分支自己舍成两位有效数字也是 `25%`**（错 A 的 0.2546 → 25%，与标准
   0.2501 → 25% 完全同形）。前瞻挡的是"带小数的写法"，挡不住"舍掉小数的写法"。

   ⚠️ **改窗宽必须机械地各造一串验边界，不能靠读正则**：「窗内最远端」「窗内最远端补零」
   「窗外最近端」三种各跑一遍。`0.5050` 与 `0.505` 是同一个数，**尾随零必须放行** ——
   把 `\d*` 收成 `[0-4]\d?|5(?![0-9])` 会把 `0.5050` 一并毙掉，那是新造的假阴性。

   ⚠️ **多坐标题要先分清哪些坐标是独立的。**把「几个坐标同时接近」当成分支证据前，
   先看题面约束：化学08 的 `δD_0 = 8.000·δ¹⁸O_0 + 4.00‰` 意味着 `ΔδD_0 ≡ 8·Δδ¹⁸O_0`，
   两者**不是独立坐标**，δD₀ 上看着"余量 13 倍"只是同一个偏差乘了 8 再拿舍入值比出来的。
   真正的独立检验是**把答复自己的参数代回各分支的积分器看残差**（化学08 run1：标准
   0.1355 最小、错 C 0.5519 是 4 倍 —— 这才判定它没走错误分支）。

   ⚠️ **分支间距 ≈ 合理容差的坐标，不能当鉴别器用。**化学08 的 `f` 上标准 0.2501 与
   错 C 0.2449 只差 2.08%，而多步数值传播的合理容差就是 2~5% —— 能放行 1.6% 误差的窗，
   离放行错 C 只剩 0.44 个百分点。鉴别负担要挪到间距/误差比最大的坐标上去。

3. **判据之间不许有蕴含关系。** 若 `A=1 ⟹ B=1` 恒成立，B 就是零判别力的白送分。
   化学07 的 `has_unit` 曾把裸 `λ` 收进关键词表，而 `target_match` 命中的前提就是文本里
   出现 `λ`——fixture 上 5/5 全 1.0。写完自检：能不能构造"其它项全中、只有它不中"的答复？

4. **治假阳性别造出假阴性。** 否决式必须把否定词**绑到被判的动作上**，不能只要求
   "否定词 + 关键词相邻"。0811 实测：`NEG + r'.{0,8}' + BASIS_KW` 被
   「(98.0 Ω) 包含扩散贡献，**不用于求本征** k⁰」触发——这是在说该用哪个电阻，不是否认
   ECSA 基准，而全文级否决**一句话就能毁掉整项**，把答对的答复判成 0。正确写法：

```python
NEG     = r'(?:不|未|非|无|没有|并不|而不|不是|无需|不必|忽略|not|without|no\b)'
NORM_KW = r'(?:归一|基准|校正|换算|归算)'
GEO_KW  = r'(?:几何|geo|投影)'
negated = has_any(text, [
    # 跨度内禁 `而`：挡住「不是几何面积**而是** ECSA 基准」这类对比句
    NEG + r'[^。；\n而]{0,8}' + BASIS_KW + r'[^。；\n而]{0,4}' + NORM_KW,
    r'(?:not|without|no)\s+(?:\w+\s+){0,2}' + BASIS_KW + r'\s*(?:\w+\s+){0,1}normali[sz]',
    # 反向语序；排除否定词紧跟几何/geo 的对比句
    BASIS_KW + r'[^。；\n而]{0,6}' + NEG + r'(?!\s*' + GEO_KW + r')'
    + r'[^。；\n而]{0,4}' + NORM_KW,
])
scores["has_basis"] = 1.0 if (has_any(text, [BASIS_KW]) and not negated) else 0.0
```

   **收窄窗宽没用**：拆掉 LaTeX 壳后字数会变（`热致 \(6\pi\) 电环化` 在 raw 档撑破窗、
   在 normalized 档又落进窗内），只有绑动作 + 否定前瞻管用。写完否决式**必须用正反例各
   5 条以上过一遍**（该命中的否认句 + 不该命中的无辜句）。

第四算子（复述题面 + 拒答）专打「答复里的数可以来自题面」这条路 —— 前三个算子都需要一份
真实答复做底本、扰动的是已有答复，数值扰动还会把题面里的常数一起扰掉，所以它们碰不到这
个错误。它的输入是「题面原文 + 一句软拒答」，**理想得分 0.000，拿到任何分都是缺陷**。
0812 起已落地成 `scripts/audit_restate_refuse.py`，不必再手写。

地板占比应低于 30%，第四算子应为 0.000。任一算子高于 50% 说明这道题测不出模型能力，
回来重写判据。化学十题 0812 已全部做到四个算子下 0.000。
回归闸门 [1]~[3] 变红**一律不许刷新**，只有 [4] 允许 `scripts/refresh_regression.py`。

另有三条结构性要求：

- **答案是标号而非数值时**（构型描述符、晶系、哪支解、哪个通道），量纲门的对应物是
  「结论属性贴结论标号」：属性词要变成标号的邻接条件，窗宽按真实写法量、允许不对称，
  且**不许做全局去分隔符压缩**（会让跨句字符巧合伪造命中）。
- **每条扣分项必须在 `raw` / `normalized` / `no_subscript` 三档里罚分集合完全一致**。
  `_robust_grade` 取总分最高那一档的整份 detail，罚分在任一档失配即被整体逃掉。
  配套的两个窗方向相反：剪枝窗按句读断（停止集**无**逗号），罚分项自己的连接窗要窄且吃逗号。
- **判据改名/合并/删除必须同commit 改 `tests/fixtures/conclusion-label-pairs.json`**，
  并核对 `covered_by` 与实现一致、翻面替换串没抹掉本题自己的扣分项。

```python
def grade(transcript: list, workspace_path: str, meta: dict) -> dict:
    import re

    def flatten_text(items):
        # 不必加 str 护栏：0811 起 `lib/task_loader.py` 的 `_robust_grade` 入口已把
        # str 形态的 transcript 归一成 list（20/20 题实测 str 档 == list 档）。
        # 题内再加一层是防御调用方，会让后来的人以为这是题目该管的事。
        parts = []
        for item in items:
            if isinstance(item, dict):
                for key in ("content", "text", "message", "output"):
                    value = item.get(key)
                    if isinstance(value, str):
                        parts.append(value)
            elif isinstance(item, str):
                parts.append(item)
        return "\n".join(parts)

    def has_any(text, patterns):
        return any(re.search(p, text, flags=re.IGNORECASE) for p in patterns)

    def strip_reasoning(s):
        # 闭合的 <think>…</think> 直接删；未闭合（答复在思考中被截断）丢弃其后全部
        # 内容，避免把推理里试算过的候选值误判成最终答案。
        s = re.sub(r'<(think|thinking|reasoning)>.*?</\1>', ' ', s,
                   flags=re.IGNORECASE | re.DOTALL)
        return re.split(r'<(?:think|thinking|reasoning)>', s, flags=re.IGNORECASE)[0]

    raw = strip_reasoning(flatten_text(transcript))
    # 归一化：统一负号/上标/乘号，展平 \frac，剥 \boxed/\text/$/**，
    # 否则「写法差异」会被记成「答错」（\dfrac 写法曾让整条判据判 0）。
    text = raw.lower()
    scores = {}

    # 1. 结论数值 + 相邻单位一起判：抽不到、单位不贴着数值、量纲不对，都是 0。
    #    不要拆成 target_extracted / has_unit 两项（白拿项②③）。
    # scores["target_with_unit"] = 1.0 if (m and within_tol(...)) else 0.0

    # 2. 中间量：一项一个量，只收"算过才写得出"的派生值。
    # scores["has_intermediate"] = ...

    # 3. 文字结论/基准：数值锚 + 否定否决（见上方 negated 写法）。
    # scores["has_basis"] = ...

    # 4. 陷阱写成扣分项，缺值不加不扣（白拿项④）。
    # penalty = 0.25 if (v is not None and within_tol(v, 陷阱值, 0.03)) else 0.0

    # 5. 加权折算。权重只落在「答对才拿得到」的项上，不给非空/非拒答留权重。
    scores["auto_final_answer_score"] = 0.0
    return scores
```

## LLM Judge Rubric

大模型评分负责**过程、概念和逻辑**，不重复判定代码侧已覆盖的最终数值命中。
3~5 个 Criterion，每个写清 `Weight`；分档按本题判分逻辑**专题定制**（档数与间距非固定，
对致命陷阱可直接给 0.0）。每一档都要对应真实可判、互斥、可回落原文的表现。

两条化学题专有的前言要求：

- 若本题存在"错误分支也能精确穿过观测"的情况，**必须在前言写明"残差为零不构成正确性
  证据"**，要求裁判看模型是否从标准态/基准定义上论证，而不是看它是否声称闭合。
- 若最终答案只保留有限位有效数字、实质建模错误会被舍入抹平，判别力要交给一个**中间量**
  承担，并在前言点明。

- 各 Criterion 的最高档要**各绑一件互相独立、可回落原文的产物**（某中间量是否落到数值、
  基准换算是否留痕、所依据的方程是否写出、闭合是否给出可核对的数值），不要统统压在
  "有没有讲理由"上——否则做对的模型会一起塌到同一档。
- 最高档以标准答案为上锚：写完做一次校准，把标准答案自己送同一裁判评一遍，应逐项拿最高档。
