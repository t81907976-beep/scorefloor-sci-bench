# 构造高质量-query	
某盐水样在25.0 ℃下蒸发,环境空气的传感器相对湿度读数恒为70.0%。传感器相对湿度以同温纯水的饱和水蒸气压为基准,25.0 ℃时纯水饱和水蒸气压p°=3.168 kPa。设f为已蒸发水量占初始水量的分数,盐不挥发,液相始终均一,水活度满足aw=1−0.100f,其中系数0.100为无量纲常数。Craig-Gordon模型中相对于溶液界面饱和水蒸气压的湿度为h=RH/aw,其中RH=70.0%=0.700。对18O,平衡分馏因子α18=1.0092、动力学分馏项εk,18=0.0060；对D,平衡分馏因子αD=1.0740、动力学分馏项εk,D=0.0050,以上各量均为无量纲。环境水汽的δ18O=−20.0‰ VSMOW、δD=−150.0‰ VSMOW。定义R/Rstd=1+δ/1000；对每一种同位素,蒸发通量的同位素比满足RE=(R/α−hRa)/(1−h+εk),有限水库守恒方程为d[(1−f)R]/df=−RE。初始水还满足同位素约束δD,0=8.000δ18O,0+4.00‰,其中斜率8.000为无量纲,截距为4.00‰ VSMOW。末态测得δ18O=−3.44‰ VSMOW、δD=−56.0‰ VSMOW。在−30‰≤δ18O,0≤20‰、−250‰≤δD,0≤20‰及0≤f≤0.60的范围内,反演参数组(δ18O,0,δD,0,f)。
# SFT标准-response	
1. 相对湿度基准与水活度修正
传感器的RH以同温纯水饱和蒸气压p°为基准,因此空气水蒸气分压为
p空气=0.700×3.168=2.2176 kPa。
盐水界面的饱和水蒸气压为awp°,其中aw=1−0.100f,故Craig–Gordon模型所需的界面归一化湿度是
h(f)=p空气/(awp°)=0.700/(1−0.100f),
而不是0.700或0.700aw。由于0≤f≤0.60,有0.940≤aw≤1、0.700≤h≤0.74468<1,因此两种同位素的分母1−h+εk均为正,模型在搜索区间内无奇点并保持净蒸发条件。

2. 转换为同位素比
令r=R/Rstd=1+δ/1000。环境水汽为
ra,18=0.980000,ra,D=0.850000；
末态观测为
rf,18=0.996560,rf,D=0.944000。
设初始δ18O为t‰,则
r0,18=1+t/1000,
δD,0=8t+4.00‰,
r0,D=1+(8t+4.00)/1000。
守恒必须在R或等价的r空间中处理,不能直接把δ值当作同位素比代入。

3. 建立动态有限水库方程
题给蒸发通量同位素比为
rE=[r/α−h(f)ra]/[1−h(f)+εk]。
由
d[(1−f)r]/df=−rE
得到
(1−f)dr/df−r=−rE,
即
dr/df={r−[r/α−h(f)ra]/[1−h(f)+εk]}/(1−f)。
整理后为
dr/df={[1−h(f)+εk−1/α]r+h(f)ra}/[{1−h(f)+εk}(1−f)]。
这是随f变化的线性ODE,积分时必须动态更新h(f)。

4. 两种同位素的具体方程
对18O,1/α18=1/1.0092=0.99088387,因此
dr18/df=[h(0.980000−r18)+0.01511613r18]/[(1.0060−h)(1−f)]。
对D,1/αD=1/1.0740=0.93109870,因此
drD/df=[h(0.850000−rD)+0.07390130rD]/[(1.0050−h)(1−f)]。
两式使用同一个f和h(f),但使用各自的α、εk和环境水汽同位素比。

5. 联合数值反演
从f=0分别以
r18(0)=1+t/1000,
rD(0)=1+(8t+4)/1000
为初值积分,并要求在同一个f=f*处满足
r18(f*)=0.996560,
rD(f*)=0.944000。
定义末态残差（单位为‰）
F18=1000[r18(f*)−0.996560],
FD=1000[rD(f*)−0.944000],
也可用联合平方残差S²=F18²+FD²检验。数值积分和二维求根给出
t≈−8.004‰,f*≈0.2498,
从而
δD,0=8t+4.00≈−60.03‰。
精细数值根处F18和FD均近于零,即S²近于零。

6. 回代与有效数字
采用按题面精度整理的参数
δ18O,0=−8.00‰,δD,0=−60.0‰,f=0.250,
有aw=0.9750、末态h=0.700/0.9750=0.7179487。动态积分约得
r18=0.9965648,即δ18O≈−3.435‰,按题面精度为−3.44‰；
rD=0.944019,即δD≈−55.98‰,按题面精度为−56.0‰。
对应残差约为F18=0.0048‰、FD=0.019‰,联合平方残差约为3.8×10^−4‰²,均低于末态数据的末位分辨尺度。

7. 范围与唯一性
所得δ18O,0、δD,0和f均位于题定范围内。由于ODE对初始同位素比是线性的,可对每个f由18O末态反推出t,再检查D末态残差；在题定范围内该联合残差仅有一次过零。因此物理解唯一。最终按观测精度为（−8.00‰,−60.0‰,0.250）,即约蒸发25.0%。

```python
    scores["target_d18o_0"] = 1.0 if has_any(text, [
        r'-\s*8\.0[0-4]\d*\s*‰',
        r'-\s*8\.0(?![0-9])\s*(?:‰|permil|vsmow)',
        r'-\s*8\.0[0-4]\d*\s*(?:$|[^0-9])(?=[^0-9]{0,20}(?:vsmow|‰|permil))',
        r'δ?\s*1?8?\s*o\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,14}-\s*8\.0[0-4]\d*\b',
        r'δ\s*1?8\s*o\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,16}-\s*8\.0(?![0-9])',
        r'-\s*8\.00\b',
    ]) else 0.0

    #    δD_0：接受 -59.9 ~ -60.49（含严格解 -60.026），排除错A -61.24 / 错C -59.10。
    #    本题鉴别负担主要在这个坐标上（分支间距 1.0~2.4‰、模型自身误差约 0.1‰），
    #    故 v3 起权重从 0.10 提到 0.30。
    #    ⚠️ 0811 假阴性修复（物理题 §8 列为必修，与 run1 怎么裁无关）：
    #    原窗 [-60.09, -60] 与 `target_d18o_0` 的 [-8.04, -8.00] 在题面源水线
    #    `δD_0 = 8.000·δ18O_0 + 4.00‰` 下**互斥** —— δ18O_0 落在窗内最远端 -8.04
    #    时 δD_0 必为 -60.32，被原 δD 窗拒掉。逐点扫 41 个采样值，两窗同时命中的
    #    δ18O_0 区间只有 [-8.0124, -8.0000]，**仅占 0.040 窗宽的 31%**：一份算对
    #    但取值偏窗内的答复会在 δD 支上无故丢 0.10。放宽到 ±0.5‰ 一档后 41/41 可用。
    #    放宽不触错误分支：到错C -59.103 还差 0.80‰，到错A -61.239 还差 0.75‰。
    #    ⚠️ v3 删掉裸 `-\s*60\s*‰` 一支：`60` 是整数，只扰小数的探针永远碰不到
    #    （第 6 类盲区的整数变体）。三位写法（-60.0x）已完整覆盖。
    scores["target_dd_0"] = 1.0 if has_any(text, [
        r'-\s*60\.[0-4]\d*\s*‰', r'-\s*59\.9\d*\s*‰',
        r'δ?\s*d\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,14}-\s*60\.[0-4]\d*\b',
        r'δ?\s*d\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,14}-\s*59\.9\d*\b',
        r'-\s*60\.[0-4]\b',
    ]) else 0.0

    #    f ≈ 0.250：排除错A 0.2546 / 错B 0.2589 / 错C 0.2449。
    #    题面自带 "25.0 ℃"，故裸 25.0 不算命中，必须带 % 或与 f 就近绑定。
    #    ⚠️ v3 收紧（0811）：原百分号支 `\b2[45](?:\.\d)?\s*%` 放行整个
    #    24.0%~25.9%，而错A 0.2546→25.5%、错C 0.2449→24.5% 都落在里面，
    #    "三分支窗互斥"只在小数支上成立。收到 `25.0x%` 一档（标准 0.2501→25.01%）。
    #    ⚠️ v3 另删裸 `f≈0.25` 与裸 `25%` 两支：**错A 的 0.2546 舍成两位有效
    #    数字也是 `0.25` / `25%`**，与标准 0.2501 完全同形，收了就等于放行错A。
    #    物理题 §4(b) 提的「加左界前瞻 `(?<![.\d])25\s*%` 安全收回裸整数支」
    #    因此不成立：前瞻挡的是"带小数的写法"，挡不住"舍掉小数的写法"。
    #    ⚠️ 另记：`f` 这个坐标**本身不能当分支鉴别器**。要放行 run1 的 0.246 需 ≥1.639%
    #    容差，而错C 0.2449 在 2.079% 就进窗 —— 可用带宽只有 0.44 个百分点，而多步
    #    数值传播的合理容差就是 2~5%。鉴别负担已挪到间距/误差比最大的 δD_0 上。
    scores["target_f"] = 1.0 if has_any(text, [
        r'f\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,16}0\.250\d*\b',
        r'f\s*(?:_?\{?\s*0\s*\}?)?[^0-9\n]{0,16}0\.249[5-9]\d*\b',
        r'\b0\.2500\b', r'\b0\.2501\b',
        r'\b25\.0\d?\s*%',
    ]) else 0.0

    # 2. 题目要求"反演参数组"——三个坐标必须同时交付，另计一份权重。
    scores["all_three_delivered"] = 1.0 if (
        scores["target_d18o_0"] and scores["target_dd_0"] and scores["target_f"]
    ) else 0.0

    _WEIGHTS = {
        "target_d18o_0": 0.25,
        "target_dd_0": 0.30,
        "target_f": 0.25,
        "all_three_delivered": 0.20,
    }
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 分支陷阱：命中即扣分（各 0.25），一律在剪掉否证从句的 hyp 上匹配 ----
    #    错A：把纯水基准 RH=0.700 直接当界面湿度。只在"从未出现 RH/a_w 界面基准"
    #    或答案落在错A指纹上时才算真正踩坑。
    #    末尾负向前查排除 "h=0.700×a_w"（那是错B）与 "h=0.700/(1−0.100f)"（正确式）。
    #    `iface` 同时承担了旧 has_basis 的判别职能：拿到界面基准即豁免这条扣分。
    iface = has_any(text, [
        r'0\.700?\s*\)?\s*/\s*\(?\s*1\s*-\s*0\.10*',
        r'0\.700?\s*\)?\s*/\s*\(?\s*a_?w', r'h\s*\(\s*f\s*\)',
        r'h\s*[=≈约]\s*0\.71[78]', r'0\.700?\s*\)?\s*/\s*\(?\s*0\.975',
        r'0\.7179', r'0\.744[0-9]',
    ])
    scores["hit_h_constant_700"] = 1.0 if has_any(hyp, [
        r'-\s*8\.1[4-6]\d*', r'\b0\.254[0-9]\b', r'-\s*61\.[12]\d*',
    ]) or ((not iface) and has_any(hyp, [
        r'h\s*[=≈约]\s*0\.700?(?![0-9])(?!\s*[x*/·×])',
    ])) else 0.0

    #    错B：反向乘成 h=0.700·a_w。
    scores["hit_h_times_aw"] = 1.0 if has_any(hyp, [
        r'h\s*[=≈约]\s*0\.68', r'0\.6825', r'0\.700?\s*[x*]\s*a_?w',
        r'0\.700?\s*[x*]\s*\(?\s*1\s*-\s*0\.10*',
        r'-\s*8\.[23]\d*\s*‰', r'\b0\.258[0-9]\b', r'-\s*62\.[34]\d*',
    ]) else 0.0

    #    错C：h 冻结成常数后套解析幂律 r(f)=S+(r0-S)(1-f)^a（h 随 f 变时无闭式解）。
    scores["hit_h_frozen_analytic"] = 1.0 if has_any(hyp, [
        r'-\s*7\.8[89]\d*', r'\b0\.244[0-9]\b', r'-\s*59\.[01]\d*',
    ]) else 0.0

    penalty = 0.25 * (
        scores["hit_h_constant_700"] + scores["hit_h_times_aw"]
        + scores["hit_h_frozen_analytic"])

    # 追溯标记（不扣分）：只报一两个坐标。少拿的权重已经体现了这件事，
    # 再扣一次等于同一件事罚两遍。
    scores["hit_partial_answer"] = 1.0 if (
        (scores["target_d18o_0"] or scores["target_dd_0"] or scores["target_f"])
        and scores["all_three_delivered"] == 0.0
    ) else 0.0

    # 代码侧最终答复证据分：只反映最终答案是否可自动确认。
    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)

    return scores
```

## LLM Judge Rubric

大模型评分负责**过程、概念和逻辑**，不重复评价代码已经检查过的最终数值命中。若代码侧显示最终值错误，大模型仍应按过程质量独立评分，但不能替代最终答案硬检查。

本题的特殊性：错误的湿度基准分支同样能精确穿过两个末态观测（残差可压到 0），因此"我拟合上了、残差为零"**不构成**任何正确性证据。裁判必须看模型是否从**标准态定义**上论证 h 的取法，而不是看它是否声称闭合。

### Criterion 1: 湿度基准换算与 h(f) 的动态性（Weight: 30%）

**Score 1.0**: 指出传感器 RH 以**纯水**饱和蒸气压 p° 为基准，而盐水界面饱和蒸气压是 a_w p°，故 Craig–Gordon 所需的界面归一化湿度是 `h(f)=RH/a_w=0.700/(1−0.100f)`；并明确 h 随 f 单调升高、积分过程中必须逐步更新，同时排除 h≡0.700 与 h=0.700·a_w 两种错误取法。
**Score 0.6**: 正确得到 `h=RH/a_w` 并在积分中动态更新，但论证含糊——只说"要用水活度校正"而没讲清 p° 与 a_w p° 是两个不同标准态，或未交代 h 必须随 f 更新的原因。
**Score 0.3**: 方向正确（用了 RH/a_w）但把 h **冻结**成常数（取 f=0 的 0.700、末态的 0.7179 或平均值）后按常系数解处理，把随 f 变化的系数当成定值。
**Score 0.0**: 直接把传感器读数 0.700 当界面湿度代入，或反向乘成 h=0.700·a_w=0.6825，基准判断从根上错。

### Criterion 2: δ→r 换算与有限水库 ODE 建立（Weight: 25%）

**Score 1.0**: 令 `r=R/R_std=1+δ/1000` 后再代入守恒式，由 `d[(1−f)r]/df=−r_E` 与 `r_E=(r/α−h r_a)/(1−h+ε_k)` 展开得 `(1−f)dr/df−r=−r_E`，整理成 `dr/df={[1−h(f)+ε_k−1/α]r+h(f)r_a}/{[1−h(f)+ε_k](1−f)}`，并说明 18O 与 D 共用同一个 f 与 h(f)、各用自己的 α 与 ε_k。
**Score 0.6**: 完成 δ→r 换算并建立了正确的有限水库微分方程，主干正确但某一系数（1/α 展开、分母 1−h+ε_k、乘积法则展开）有次要偏差，不影响方程结构。
**Score 0.3**: 意识到需要对有限水库做动态积分，但方程建立不完整——如漏掉 ε_k 项、把分母写成 1−h、把 r_E 当常数、或未做 δ→r 换算而直接在 δ 空间套同一守恒式（后者会把 δ18O 末态算成 −14.1‰ 而非 −3.44‰，偏差 10‰ 量级）。
**Score 0.0**: 不做动态积分，直接用稳态 Craig–Gordon 单点式或纯平衡瑞利式（`δ_L=(δ_0+1000)(1−f)^(1/α−1)−1000`）套末态，把动态问题当静态问题处理。

### Criterion 3: 源水线约束与欠定性闭合（Weight: 25%）

**Score 1.0**: 明确用 `δD_0=8.000δ18O_0+4.00‰` 把 δD_0 绑定到 δ18O_0，并说清这条约束的作用是把「3 个未知量 (δ18O_0, δD_0, f) 对 2 个末态观测」的**欠定**问题闭合成唯一解——不用它则 f 在 0~0.60 全区间都能各自反解出一组 (δ18O_0, δD_0)，无法定解。
**Score 0.5**: 使用了源水线约束并据此完成两同位素联立，得到自洽结果，但未指出参数计数/欠定性问题，把这条约束当成一个普通已知条件或事后验算。
**Score 0.0**: 未使用源水线约束（把 δ18O_0、δD_0 当两个彼此独立的自由参数各自凑数），或只用单一同位素定 f 而从不检验另一同位素——两种做法都无法给出唯一解。

### Criterion 4: 二维数值求根与回代自洽性（Weight: 20%）

**Score 1.0**: 认识到 h 随 f 变化时两条 ODE 无初等闭式解，以 (δ18O_0, f) 为未知量做数值积分 + 二维联合求根，要求两条方程在**同一个** f* 处同时命中 r18=0.996560 与 rD=0.944000（或等价地最小化联合平方残差）；并按题面精度回代验证 δ18O≈−3.44‰、δD≈−56.0‰，同时检查解落在题给区间内、以及 h<1 与 1−h+ε_k>0 的模型适用条件。
**Score 0.6**: 完成了数值联合求根并得到合理解，但回代验证不完整（未给残差、未核验两个末态、或未检查区间/适用条件），或用"残差为零"当作分支正确性的证据（本题任何 h 分支都能压到零残差，该论证无效）。
**Score 0.3**: 只做单向求解或逐个同位素分别求根后声称一致，未在同一个 f* 上联立；或对唯一性只给口头断言而无扫描/单调性论证。
**Score 0.0**: 不做数值求解而给出捏造的闭式反演，或最终三个参数彼此矛盾（如报出的 f 与报出的 δ 值代回后差异远超题面 0.01‰ 分辨尺度），或声称的闭合与自己报出的参数不符。
