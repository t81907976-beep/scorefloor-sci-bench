# 构造高质量-query

某气相CO₂同位素拉曼质控装置在1250～1400 cm⁻¹范围内观察到一组双峰。候选零级态为对称伸缩ν₁和弯曲倍频2ν₂；线性CO₂中ν₁属于Σg+,而v₂=2振动流形含l=0与|l|=2分量。偏振实验测得两峰的退偏比均为0.08,未检出可归属于|l|=2分量的垂直偏振带。在本装置的检出限内,除该双峰外没有面积超过0.10归一化面积单位的第三条谱带。

独立空白谱表明,2ν₂零级态的直接积分面积小于ν₁零级积分面积的0.5%,即上限为0.005倍ν₁零级积分面积；质控数据已经扣除这一直接通道,在所需精度下将2ν₂的残余直接跃迁矩取为零,并按不存在零级跃迁矩干涉项的封闭模型处理。每组双峰扣除背景后均归一化为100归一化面积单位。

仪器给出的峰位是在实际样品压力下的拉曼位移,但同位素模型以零密度极限波数为能量基准。压力扫描显示:压力每升高20.0 kPa,同一同位素的低峰和高峰都向高波数移动0.40 cm⁻¹,而双峰间距、退偏比和归一化面积均不变；取1 bar=100.0 kPa。

碳原子质量M=12.000000 u的样品在1.500 bar下,低峰和高峰分别为1318.37 cm⁻¹与1369.63 cm⁻¹,积分面积分别为67.56与32.44归一化面积单位。碳原子质量M=13.003355 u的样品在0.500 bar下,低峰和高峰分别为1300.37 cm⁻¹与1351.63 cm⁻¹,积分面积分别为32.44与67.56归一化面积单位。已知在12～14 u范围内,两个零级态的零密度极限波数分别对实际碳原子质量M呈线性关系,允许的非谐耦合矩阵元与同位素质量及压力无关。

现将碳原子质量M=14.003242 u的CO₂装入1.000 bar质控池。请给出该质控池中最终应观察到的低、高两峰波数、归一化积分面积及各峰的主要零级归属,并据此形成一个自洽的双峰质控判定。

# SFT标准-response

1. 模型选择与对称性判据

线性CO₂中ν₁属于Σg+。弯曲基频ν₂属于Πu,其二量子对称积包含Σg+和Δg,因此v₂=2流形中的l=0分量属于Σg+,可与ν₁发生费米非谐耦合；|l|=2分量属于Δg,不能作为该Σg+二态费米共振中的第二个同对称性基态。实验又未检出相应的垂直偏振第三带,且两峰退偏比均为0.08,支持采用ν₁与(2ν₂,l=0)组成的封闭二态模型。

题目说明2ν₂直接跃迁通道已扣除,在所需精度下其残余零级跃迁矩取零,并且不存在零级跃迁矩干涉项。因此两条混合峰的剩余强度都由ν₁跃迁矩提供,归一化面积百分数可直接解释为相应本征态中的ν₁组态权重。两峰面积闭合为100且没有面积超过0.10的第三带,也支持忽略第三态。

2. 压力基准校正

压力位移系数为
kP=0.40/20.0=0.0200 cm⁻¹·kPa⁻¹=2.000 cm⁻¹·bar⁻¹。

两峰具有相同压力斜率,且间距和面积不随压力变化,所以压力只造成共同模位移,不改变失谐量、耦合量和混合系数。

碳-12样品在1.500 bar下的共同位移为3.000 cm⁻¹,故零密度峰位为
E−,12(0)=1318.37−3.00=1315.37 cm⁻¹,
E+,12(0)=1369.63−3.00=1366.63 cm⁻¹。

碳-13样品在0.500 bar下的共同位移为1.000 cm⁻¹,故
E−,13(0)=1300.37−1.00=1299.37 cm⁻¹,
E+,13(0)=1351.63−1.00=1350.63 cm⁻¹。

相应中心和间距为
C12=(1315.37+1366.63)/2=1341.00 cm⁻¹,
C13=(1299.37+1350.63)/2=1325.00 cm⁻¹,
S12=S13=51.26 cm⁻¹。

3. 二态费米共振反演

在基底(|ν₁⟩,|2ν₂,l=0⟩)中写
H=[[E1,V],[V,E2]],
定义Δ=E1−E2、C=(E1+E2)/2,则
E±=C±(1/2)S,
S=√(Δ²+4V²)。

由于只保留ν₁零级跃迁矩,低、高峰的ν₁权重分别为
f−=(1−Δ/S)/2,
f+=(1+Δ/S)/2。

碳-12中f−=0.6756,因此
Δ12=51.26[1−2(0.6756)]=−18.002512 cm⁻¹。

碳-13中f−=0.3244,因此
Δ13=51.26[1−2(0.3244)]=+18.002512 cm⁻¹。

失谐量由负变正,说明零级态在两种质量之间发生交叉,而观测峰形成避交叉。耦合矩阵元为
V=(1/2)√(51.26²−18.002512²)=23.9974 cm⁻¹。

对应零级波数为
碳-12:E1,12=1341.00−9.001256=1331.998744 cm⁻¹,E2,12=1350.001256 cm⁻¹；
碳-13:E1,13=1325.00+9.001256=1334.001256 cm⁻¹,E2,13=1315.998744 cm⁻¹。

4. 按实际碳原子质量外推

质量外推因子为
r=(14.003242−12.000000)/(13.003355−12.000000)=1.996543596。

由于两个零级波数分别对实际质量呈线性关系,其中心和失谐量也均为质量的线性函数:
C14=1341.00+(1325.00−1341.00)r=1309.055302 cm⁻¹,
Δ14=−18.002512+[18.002512−(−18.002512)]r=53.883088 cm⁻¹。

因此目标同位素的零密度双峰间距为
S14=√(53.883088²+4×23.9974²)=72.15874 cm⁻¹。

零密度峰位为
E−,14(0)=1309.055302−72.15874/2=1272.97593 cm⁻¹,
E+,14(0)=1309.055302+72.15874/2=1345.13467 cm⁻¹。

5. 换回1.000 bar实际测量基准

1.000 bar造成的共同蓝移为
δP=2.000×1.000=2.000 cm⁻¹。

所以实际观察峰位为
E−,14=1272.97593+2.000=1274.97593≈1274.98 cm⁻¹,
E+,14=1345.13467+2.000=1347.13467≈1347.13 cm⁻¹。

实际压力下间距仍为72.15874≈72.16 cm⁻¹。

6. 面积和归属

目标同位素中
f−=(1−53.883088/72.15874)/2=0.126635,
f+=0.873365。

故归一化面积为
A−=12.6635≈12.66,
A+=87.3365≈87.34。

由于Δ14>0,即ν₁零级波数高于(2ν₂,l=0)零级波数,低峰主要为(2ν₂,l=0),其权重约87.34%；高峰主要为ν₁,其ν₁权重约87.34%。

最终自洽质控判定为:在M=14.003242 u、1.000 bar条件下,应出现1274.98和1347.13 cm⁻¹两峰,面积分别约12.66和87.34,低峰主要为(2ν₂,l=0),高峰主要为ν₁；两峰退偏比均约0.08,且不应出现面积超过0.10的第三条带。这体现了跨越零级交叉后由费米避交叉引起的强度转移。

```python
             r'upper[- ]?(?:peak|band))')
    _A_LOW = r'(?:' + _LB + r'a\s*[-_]\s*(?:,\s*)?[=≈:：(]|' + _LOW + r')'
    _A_HIGH = r'(?:' + _LB + r'a\s*[+_]\s*(?:,\s*)?[=≈:：(]|' + _HIGH + r')'

    scores = {}

    # ---- 1. 低峰 1274.98 cm^-1（1.000 bar 实测基准）+ 相邻量纲 ----
    #    低峰承担主要判别力：它把错 A/B/C（压力处理）与错 D（整数质量）全部排除。
    scores["target_low_peak"] = 1.0 if (
        in_win(1274.93, 1275.03)
        and near(r'(?<![\d.])127[45]\.\d+(?![\d])', _UNIT, ahead=26, behind=40)
    ) else 0.0

    # ---- 2. 高峰 1347.13 cm^-1 ----
    #    错 D 的 1347.126 落在同一两位小数上，本项不承担排除整数质量的职责。
    scores["target_high_peak"] = 1.0 if (
        in_win(1347.08, 1347.19)
        and near(r'(?<![\d.])134[67]\.\d+(?![\d])', _UNIT, ahead=26, behind=40)
    ) else 0.0

    # ---- 3. 两个面积，且各自贴到所属的峰 ----
    #    只判"全文出现 12.66 与 87.34"会让归属对调的错 G 白拿，必须绑峰。
    scores["target_areas_bound"] = 1.0 if (
        (val_near(_A_LOW, 12.64, 12.69, ahead=90, behind=40)
         or val_near(r'(?<![\d.])1274\.9\d*(?![\d])', 12.64, 12.69,
                     ahead=120, behind=40))
        and (val_near(_A_HIGH, 87.30, 87.38, ahead=90, behind=40)
             or val_near(r'(?<![\d.])1347\.1\d*(?![\d])', 87.30, 87.38,
                         ahead=120, behind=40))
    ) else 0.0

    # ---- 4. 压力基准换算：两个零密度中心都要落地 ----
    #    C12=1341.00 与 C13=1325.00 是"做过零密度换算才写得出"的派生量，
    #    错 A/B/C 各自给出 1344.00 / 1347.00 / 1343.97，三支互斥。
    scores["zero_density_centers"] = 1.0 if (
        in_win(1340.97, 1341.03) and in_win(1324.97, 1325.03)
    ) else 0.0

    # ---- 5. 失谐符号翻转：±18.00 都要有，且 Δ14 已按翻转后的值外推 ----
    #    单看 |18.00| 无法区分错 E（Δ13 未翻号）；把 Δ14=+53.88 并联进来，
    #    它只有在两个 Δ 反号时才出现（错 E 得 −18.003）。
    scores["detuning_sign_flip"] = 1.0 if (
        in_win(-18.06, -17.95) and in_win(17.95, 18.06)
        and in_win(53.83, 53.94)
    ) else 0.0

    # ---- 6. 耦合矩阵元 V≈24.00 cm^-1 + 符号邻接 ----
    _V_TOK = (r'\|\s*[vw]\s*\||' + _LB + r'[vw]\s*[=≈]|耦合(?:常数|矩阵元|强度)?|'
              r'coupling|费米|fermi')
    scores["coupling_matrix_element"] = 1.0 if (
        val_near(_V_TOK, 23.96, 24.04, ahead=40, behind=25)
        and near(r'(?<![\d.])2[34]\.\d+(?![\d])|(?<![\d.])24(?![\d.])',
                 _UNIT, ahead=24, behind=40)
    ) else 0.0

    # ---- 7. 派生中间量：需多步代入才写得出的量 ----
    #    r=1.99654 不收（两次减法一次除法即得，A2.5 禁止题给常数的简单组合），
    #    收的是必须先做压力换算 + 面积反演 + 平方根传播才出现的量。
    scores["derived_intermediate"] = 1.0 if (
        in_win(72.11, 72.21)          # S14=72.15874
        or in_win(1309.00, 1309.11)   # C14=1309.0553（注意与整数质量 1309.000 相邻，
                                      # 故本项只作追加证据，不承担判别错 D 的职责）
        or in_win(1331.96, 1332.04)   # 零级 E1,12=1331.9987
        or in_win(1349.96, 1350.04)   # 零级 E2,12=1350.0013
        or in_win(1315.96, 1316.04)   # 零级 E2,13=1315.9987
        or in_win(12.495, 12.508)     # 零级交叉质量 12.5017 u
    ) else 0.0

    # ---- 8. 主零级归属已翻转（纯文字结论 → 数值锚 + 否定否决）----
    #    数值锚：面积已正确绑峰（错 G 在所有数值上与标准同形，只有这一项能分开它）。
    _2N2 = r'2\s*ν\s*2|2ν2|\(\s*2\s*ν\s*2\s*,?\s*l\s*=\s*0\s*\)|弯曲倍频|倍频'
    _N1 = r'ν\s*1|对称伸缩|symmetric\s+stretch'
    assign_ok = has_any(text, [
        _LOW + r'[^。；\n]{0,30}(?:主要|主体|主导|以|为|归属|assign)?'
        r'[^。；\n]{0,12}(?:' + _2N2 + r')',
        _HIGH + r'[^。；\n]{0,30}(?:主要|主体|主导|以|为|归属|assign)?'
        r'[^。；\n]{0,12}(?:' + _N1 + r')',
    ])
    _NEG = r'不|未|非|无|没有|并不|而不|不是|无需|不必|忽略|not|without|no\b'
    # 否决：把归属说成"低峰=ν₁"或"高峰=2ν₂"（即碳-12 的归属，未识别交叉）。
    # 跨度里禁掉否定词与"而"，避免「低峰不再是 ν₁ 而是 2ν₂」这类对比句触发。
    _NOSTOP = r'[^。；\n而不未非无没]'
    assign_negated = has_any(text, [
        _LOW + _NOSTOP + r'{0,14}(?:主要|主体|主导|为|是|归属)' + _NOSTOP + r'{0,8}'
        r'(?:' + _N1 + r')',
        _HIGH + _NOSTOP + r'{0,14}(?:主要|主体|主导|为|是|归属)' + _NOSTOP + r'{0,8}'
        r'(?:' + _2N2 + r')',
    ])
    scores["assignment_crossed"] = 1.0 if (
        assign_ok and not assign_negated
        and scores["target_areas_bound"] == 1.0
    ) else 0.0

    _WEIGHTS = {
        "target_low_peak": 0.22,
        "target_high_peak": 0.14,
        "target_areas_bound": 0.18,
        "zero_density_centers": 0.14,
        "detuning_sign_flip": 0.12,
        "coupling_matrix_element": 0.08,
        "derived_intermediate": 0.06,
        "assignment_crossed": 0.06,
    }
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 陷阱：命中才扣，缺值不加不扣（A2.1 白拿项④）----
    #    错 A/B/C：压力基准处理错 → 双峰整体平移。
    #    ⚠️ 这三支必须以「标准低峰缺失」为前提：正确解法在中途一定会写出零密度峰位
    #    1272.976 / 1345.135，而它与错 B 的**最终交付值** 1272.990 / 1345.149 只差
    #    0.014 —— 纯数值窗无法把"中间量"与"错误终值"分开，不加门就会反扣标准答案
    #    （实测标准答案被这一支扣掉 0.25）。
    scores["hit_pressure_baseline"] = 1.0 if (
        (in_win(1271.94, 1272.03) or in_win(1272.95, 1273.04)
         or in_win(1273.95, 1274.04)
         or in_win(1343.97, 1344.03) or in_win(1346.97, 1347.03))
        and scores["target_low_peak"] == 0.0
    ) else 0.0

    #    错 D：整数质量 → 低峰 1274.874、A-=12.6254、Δ14=54.008。
    #    上界 12.638 严格小于接受窗下界 12.64，两窗不重叠。
    scores["hit_integer_mass"] = 1.0 if (
        (in_win(1274.82, 1274.92) or in_win(12.600, 12.638)
         or in_win(53.98, 54.05))
        and scores["target_low_peak"] == 0.0
    ) else 0.0

    #    错 E：Δ13 未翻符号 → 不识别零级交叉，双峰 1285.43/1336.69。
    scores["hit_no_sign_flip"] = 1.0 if (
        in_win(1285.38, 1285.48) or in_win(1336.64, 1336.74)
    ) else 0.0

    #    错 F：V 取一半 → 双峰 1281.56/1340.55，A-=4.33。
    scores["hit_V_halved"] = 1.0 if (
        in_win(1281.51, 1281.61) or in_win(1340.50, 1340.60)
        or (in_win(4.28, 4.37) and in_win(95.60, 95.72))
    ) else 0.0

    #    错 G：数值全对但归属说反（低峰=ν₁ / 高峰=2ν₂）。
    scores["hit_assignment_swapped"] = 1.0 if assign_negated else 0.0

    penalty = 0.25 * (scores["hit_pressure_baseline"] + scores["hit_integer_mass"]
                      + scores["hit_no_sign_flip"] + scores["hit_V_halved"]
                      + scores["hit_assignment_swapped"])

    # ---- 零权重追溯字段 ----
    scores["trace_avoided_crossing"] = 1.0 if has_any(text, [
        r'避交叉|avoided\s+crossing|反交叉|anticrossing',
    ]) else 0.0
    scores["trace_unit_matrix_argument"] = 1.0 if has_any(text, [
        r'单位矩阵|identity\s+matrix|正比于\s*i\b|共同(?:模)?位移|同步(?:蓝)?移',
    ]) else 0.0

    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)
    return scores
```
