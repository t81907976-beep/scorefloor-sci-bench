# 构造高质量-query	
某闭壳层供体—受体二联体经光激发后,在电子系间窜越发生以前通过自旋守恒的电荷转移生成自由基对,因此自由基对的初始电子态为单重态。自由基1仅含一个质子核,质子超精细耦合常数以磁场单位表示为A=+0.200 mT；两个自由基的电子g因子差定义为Δg=g1−g2=−1.00×10^-3,电子平均g因子为g=2.0023。自由基对从单重态以速率kS=2.00×10^7 s^-1生成产物,从三重态以速率kT=5.00×10^6 s^-1逃逸为不被检测的产物；电子自旋相干的纯退相干率为γφ=1.00×10^6 s^-1。这里γφ定义为密度矩阵元ρST的直接衰减率,即退相干项满足(dρST/dt)φ=−γφρST,且该退相干不改变ρSS和ρTT。测量装置只记录单重态通道生成的产物,记录时间足够长,可视为积分至t=∞。两种核自旋初态未经过射频制备,且前体为闭壳层、未提供核自旋选择；298 K下质子的热平衡极化相对于完全混合分布的修正小于10^-6,因此可由此确定两个初始核自旋态的统计权重。本题采用每个固定核自旋组态内的S–T0相干模型作为有效自旋动力学模型,T±态及核自旋翻转耦合不纳入该模型。磁场取B低=10.0 mT和B高=200.23 mT,测量温度为298 K。电子旋磁比为γe=1.76086×10^11 rad s^-1 T^-1；298 K时质子的平衡极化为P_eq=(3.4285×10^-6 T^-1)B,其中B以T代入。规定热平衡正峰为吸收,产物质子极化定义为P产物=(Y+−Y−)/(Y++Y−),其中Y+和Y−分别是产物中m=+1/2和m=−1/2核自旋组态的绝对产率；CIDNP响应定义为带符号的R(B)=P产物/P_eq。求R(B)在上述两个磁场下的数值,并判定各自相对于热平衡谱是增强吸收相还是发射相,结果按两位有效数字报告。
# SFT标准-response	
1. 有效模型与初态
题目明确指定每个固定核自旋组态内的S–T0相干模型,因此只处理S与T0,不加入T±或核自旋翻转。电子初态为单重态:pS(0)=1,pT(0)=0,ρST(0)=0。

严格的核自旋初始权重为
w±=(1±P_eq)/2。
由于P_eq<10^-6,取w+=w-=1/2已足以得到所要求的两位有效数字；下面保留该修正对最终比值的说明。

2. 相干衰减率
Haberkorn反应损失使S–T0相干按(kS+kT)/2衰减,题给纯退相干又直接使ρST按γφ衰减。因此
K=(kS+kT)/2+γφ
=[(2.00×10^7+5.00×10^6)/2+1.00×10^6] s^-1
=1.35×10^7 s^-1。

3. 固定核组态的S–T0耦合
γe按平均g因子g定义,所以g因子差产生的有效磁场差为(Δg/g)B。对m=±1/2,
δB_m=(Δg/g)B+mA,
Ω_m=(γe/2)δB_m。
其中A=0.200 mT,故mA=±0.100 mT；Ω_m是S–T0哈密顿量的非对角角频率。

4. 积分单重态产率
令v=ImρST,则
ṗS=−kS pS−2Ω_m v,
ṗT=−kT pT+2Ω_m v,
v̇=Ω_m(pS−pT)−Kv。

定义
x=∫₀∞pSdt,y=∫₀∞pTdt,z=∫₀∞vdt。
积分后得到
1=kSx+2Ω_mz,
kTy=2Ω_mz,
Kz=Ω_m(x−y)。

令
q_m=2Ω_m²/K,
则固定核组态的单重态产率为
ΦS(m)=kSx=kS(kT+q_m)/[kSkT+q_m(kS+kT)]。
这是相干方程的精确积分结果,不要求|Ω_m|≪K。

因此
δB_+=−0.0049943+0.100000=+0.0950057 mT,
δB_−=−0.0049943−0.100000=−0.1049943 mT。

换算成T后,
|Ω_+|=(1.76086×10^11/2)(0.0950057×10^-3)
=8.3646×10^6 s^-1,
|Ω_−|=(1.76086×10^11/2)(0.1049943×10^-3)
=9.2440×10^6 s^-1。

于是
q_+=2Ω_+²/K=1.03654×10^7 s^-1,
q_−=2Ω_−²/K=1.26595×10^7 s^-1,
并得到
ΦS(+)=0.85569,
ΦS(−)=0.84802。

忽略不到10^-6的初始热权重偏差时,
P0=[ΦS(+)−ΦS(−)]/[ΦS(+)+ΦS(−)]
=4.50×10^-3。

严格使用w±=(1±P_eq)/2时,
P产物=(P0+P_eq)/(1+P0P_eq),
与P0只相差约P_eq,对两位有效数字无影响。

低场平衡极化为

故
R(10.0 mT)=P产物/P_eq≈1.31×10^5,

6. 高场B=200.23 mT
(Δg/g)B=[−1.00×10^-3/2.0023](200.23 mT)
=−0.100000 mT。
因此
δB_+=−0.100000+0.100000=0,
δB_−=−0.100000−0.100000=−0.200000 mT。

对m=+1/2,Ω_+=0,所以没有S–T0混合,
ΦS(+)=1。

对m=−1/2,
|Ω_−|=(1.76086×10^11/2)(0.200000×10^-3)
=1.76086×10^7 s^-1,
q_−=2Ω_−²/K=4.59352×10^7 s^-1,
从而

```python
    raw = re.sub(r'\\[tdc]?frac\s*\{([^{}]*)\}\s*\{([^{}]*)\}', r'(\1)/(\2)', raw)
    for _ in range(3):
        raw = re.sub(r'\\(?:boxed|text|mathrm|mathbf|operatorname|rm|bf|it)'
                     r'\s*\{([^{}]*)\}', r'\1', raw)
    raw = re.sub(r'\\[,;:!]|\\ ', ' ', raw)
    for ch in ("$", "\\(", "\\)", "\\[", "\\]"):
        raw = raw.replace(ch, " ")
    raw = raw.replace("**", " ")
    text = raw.lower()

    _SCI = (r'([+-]?\s?\d+(?:\.\d+)?)\s*(?:x|\*)\s*10\s*\^?\s*\{?\s*([+-]?\d+)\s*\}?'
            r'|([+-]?\s?\d+(?:\.\d+)?)\s*e\s*\^?\s*\{?\s*([+-]?\d+)\s*\}?')

    def signed_sci(seg):
        """片段内的带符号科学计数值。负号紧贴数字时记为负，
        用于区分 R=+1.3x10^5（吸收）与 R=-1.3x10^5（发射，错 G）。"""
        out = []
        for m in re.finditer(_SCI, seg):
            mant = m.group(1) or m.group(3)
            exp = m.group(2) or m.group(4)
            try:
                out.append(float(mant.replace(" ", "")) * 10.0 ** int(exp))
            except (ValueError, OverflowError):
                pass
        return out

    def numbers(s):
        vals = signed_sci(s)
        for m in re.finditer(
                r'(?<![\d.eE^])([+-]?\d{1,7}(?:\.\d+)?)'
                r'(?![\d.]*\s*(?:\^|x\s*10|e[+-]?\d))', s):
            try:
                vals.append(float(m.group(1)))
            except ValueError:
                pass
        return vals

    nums = numbers(text)

    def in_win(lo, hi):
        return any(lo <= v <= hi for v in nums)

    def has_any(t, patterns):
        return any(re.search(p, t, flags=re.IGNORECASE) for p in patterns)

    scores = {}

    _F_LOW = r'(?<![\d.])10\.0(?![\d])\s*0*\s*m?t?'
    _F_HIGH = r'(?<![\d.])200\.23(?![\d])'
    _R_TOK = r'\br\s*[(\[=≈]|cidnp|响应'

    def r_at(field, lo, hi):
        """R 值必须**与它所属的磁场绑定**，不是"全文出现过某个落窗数值"。
        绑定两条路：磁场标记后 200 字符内出现落窗的带符号值，或落窗值往前
        70 字符内同时出现磁场标记与 R/CIDNP 语义。两条路都要求片段里有
        R 语义词，避免把 P产物、q、|Ω| 这些中间量当成 R 交付。"""
        for m in re.finditer(field, text):
            seg = text[m.start():m.end() + 200]
            if not re.search(_R_TOK, seg, re.IGNORECASE):
                continue
            for v in signed_sci(seg):
                if lo <= v <= hi:
                    return True
        for m in re.finditer(_SCI, text):
            mant = m.group(1) or m.group(3)
            exp = m.group(2) or m.group(4)
            try:
                v = float(mant.replace(" ", "")) * 10.0 ** int(exp)
            except (ValueError, OverflowError):
                continue
            if not (lo <= v <= hi):
                continue
            back = text[max(0, m.start() - 70):m.start()]
            if re.search(field, back) and re.search(_R_TOK, back, re.IGNORECASE):
                return True
        return False

    # 1. 两个磁场的 R，窗口按上表的错误分支指纹互斥设计，且要求正号 + 磁场绑定。
    #    R(10.0 mT)=+1.3129e5：窗口 1.26~1.36e5
    scores["target_R_low"] = 1.0 if r_at(_F_LOW, 1.26e5, 1.36e5) else 0.0
    #    R(200.23 mT)=+1.4758e5：窗口 1.44~1.53e5（容纳标准答案原文的 1.48e5）
    scores["target_R_high"] = 1.0 if r_at(_F_HIGH, 1.44e5, 1.53e5) else 0.0

    # 2. 相位判定：两个磁场都必须判成（增强）吸收相，且不得把结论定成发射相。
    #    必须是模型自己下了结论，不能是复述题面的二选一提问——先整体删掉含"还是"
    #    的选择从句（题面原句"…是增强吸收相还是发射相"），再删掉显式否定
    #    （"而不是发射相"），剩下的才算模型的判定。
    #    **相位不能单独计分**：它是纯文本结论，把题面两个词抄一个就白拿 0.15，
    #    数值扰动下 5/5 存活（实测）。因此要求至少一个 R 已落窗——相位是对
    #    已交付数值的符号解读，没有数值就没有可解读的对象。
    phase_text = re.sub(r'[^。\n；;]{0,40}还是[^。\n；;]{0,30}', ' ', text)
    phase_text = re.sub(r'(?:不是|而非|非|不属于|不为|排除|并非|而不是)[^。\n；;]{0,10}发射',
                        ' ', phase_text)
    phase_text = re.sub(r'发射[^。\n；;]{0,6}(?:错|不对|不成立|排除)', ' ', phase_text)
    claims_emission = has_any(phase_text, [
        r'发射\s*相', r'为发射', r'是发射', r'均.{0,4}发射', r'都.{0,4}发射',
        r'emissive', r'emission\s+phase',
    ])
    claims_absorption = has_any(phase_text, [
        r'(?:增强)?吸收\s*相', r'增强吸收', r'吸收增强',
        r'absorptive', r'enhanced\s+absorption',
    ])
    scores["phase_absorption"] = 1.0 if (
        claims_absorption and not claims_emission
        and (scores["target_R_low"] or scores["target_R_high"])
    ) else 0.0

    # 3. 相干总衰减常数 K=1.35e7 s^-1（(kS+kT)/2 与 γφ 两项都在）。
    #    本项是唯一能把错 A 与标准解分开的硬检查（两位有效数字下 R 相同）。
    #    **只收数值，删掉符号式旁路**：原实现允许"只写 (kS+kT)/2+γφ 不给数值"，
    #    于是纯数值扰动下 4/5 存活——符号式与裸串互相救活，等于没有检查。
    #    1.35e7 是 (2.0e7+7.0e6)/2+1.0e6 的推导结果，题面不含此值。
    scores["coherence_rate_K"] = 1.0 if (
        in_win(1.340e7, 1.360e7) or re.search(r'13\s*500\s*000', text)
    ) else 0.0

    # 4. 高场 m=+1/2 的精确抵消：(Δg/g)*200.23 mT = -0.100 mT 恰好等于 -mA。
    #    这是 200.23 这个非整数磁场的构造意图，套模板算不出来。
    #    **表述 + 数值双闸**：光有"恰好抵消"四个字是纯文本判据（题面 hint 里
    #    也有"抵消"），必须同时给出可核验的数值证据之一：
    #    带符号的 (Δg/g)B=-0.100 mT、ΦS(+)=1.00、或高场 ΦS(-)=0.816。
    canc_claim = has_any(text, [
        r'(?:精确|完全|恰好|正好|刚好|近似完全)\s*(?:地)?\s*'
        r'(?:抵消|相消|抵销|对消|消去|补偿|为零|归零)',
        r'(?:补偿点|抵消点)',
        r'(?:不(?:发生|存在|再)|没有|无)\s*s\s*[-–—]?\s*t\s*0?\s*(?:的)?\s*混合',
        r'混合\s*(?:被)?\s*(?:完全)?\s*(?:关闭|消失|抑制)',
        r'(?:exact|exactly|precisely|completely)\w*\s+cancel',
        r'cancel\w*\s+(?:exactly|precisely|completely)',
        r'no\s+s\s*[-–—]?\s*t\s*0?\s+mixing',
    ])
    canc_num = has_any(text, [
        r'(?:δ\s*g|delta\s*g)[^。\n]{0,44}?-\s*0\.100(?![\d])',
        r'(?:φ|phi|y|Φ)\s*_?\s*s?\s*\(?\s*\+\s*(?:1\s*/\s*2)?\s*\)?'
        r'\s*[≈=]\s*1\.0{2,}(?![\d])',
        r'(?<![\d.])0\.81[56]\d*(?![\d])',
    ])
    scores["highfield_cancellation"] = 1.0 if (canc_claim and canc_num) else 0.0

    # 5. 关键中间量：ΦS / q / |Ω| / P产物 / P_eq / δB。
    #    只收**推导出来的**值。已剔除 P产物 低场窗 4.48~4.53e-3：区间太宽、
    #    量级太常见，`--integers` 扰动能撞出 0.0045（实测 run5 假阳性）。
    scores["derived_intermediate"] = 1.0 if (
        in_win(0.8550, 0.8565) or in_win(0.8474, 0.8487)         # ΦS 低场 0.85569/0.84802
        or in_win(0.8153, 0.8168)                                 # ΦS 高场 0.81602
        or in_win(1.030e7, 1.043e7) or in_win(1.259e7, 1.273e7)   # q 低场
        or in_win(4.56e7, 4.63e7)                                 # q 高场 4.5935e7
        or in_win(8.33e6, 8.40e6) or in_win(9.21e6, 9.28e6)       # |Ω| 低场
        or in_win(1.758e7, 1.764e7)                               # |Ω| 高场
        or in_win(0.1008, 0.1018)                                 # P产物 高场 0.10131
        or in_win(3.41e-8, 3.45e-8) or in_win(6.83e-7, 6.90e-7)   # P_eq 两个磁场
        or has_any(text, [
            r'(?<![\d.])0\.0049\d*', r'(?<![\d.])0\.09500\d*',
            r'(?<![\d.])0\.10499\d*',
        ])
    ) else 0.0

    _WEIGHTS = {
        "target_R_low": 0.25,
        "target_R_high": 0.25,
        "phase_absorption": 0.15,
        "coherence_rate_K": 0.12,
        "highfield_cancellation": 0.13,
        "derived_intermediate": 0.10,
    }
    earned = sum(w for k, w in _WEIGHTS.items() if scores[k] == 1.0)

    # ---- 陷阱标记：命中即扣分，不再只是"供追溯" ----
    #    反向项若只记录不扣分，等于把"答错"和"没答"抹平；四条主干错误各扣 0.25。
    #    错 A：K 漏掉纯退相干（K=1.25e7）。两位有效数字下 R 与标准解撞车，
    #    只能靠 K 本身识别，因此这里同时看数值窗口与"忽略退相干"的表述。
    scores["hit_K_no_dephasing"] = 1.0 if (in_win(1.245e7, 1.255e7) or has_any(text, [
        r'k\s*[≈=]\s*1\.25\s*(?:x|\*)?\s*10\s*\^?\s*7',
        r'(?:忽略|不计|不含|无需(?:考虑)?)\s*(?:纯)?退相干',
    ])) else 0.0

    #    错 D：Δg 项不除平均 g → 高场抵消被破坏，R≈2.6e5 / 3.9e4。
    #    3.9e4 是错 D 与错 F 的共有高场指纹，靠低场区分：2.6e5 归 D、2.6e4 归 F。
    scores["hit_g_reference"] = 1.0 if in_win(2.55e5, 2.72e5) or (
        in_win(3.75e4, 3.98e4) and not in_win(2.55e4, 2.70e4)
    ) else 0.0

    #    错 K：P_eq 里 B 用 mT 数值代入（漏 1e-3 换算）→ R 塌到 1.3e2 / 1.5e2。
    scores["hit_field_unit"] = 1.0 if (
        in_win(1.28e2, 1.34e2) and in_win(1.45e2, 1.50e2)
    ) else 0.0

    #    陷阱：把相位判成发射相（错 G 符号翻转 / 错 I 三重态通道 / 错 J 初态混合）。
    scores["hit_emission_phase"] = 1.0 if claims_emission else 0.0

    penalty = 0.25 * (
        scores["hit_K_no_dephasing"] + scores["hit_g_reference"]
        + scores["hit_field_unit"] + scores["hit_emission_phase"]
    )

    # ---- 以下仅供追溯，不参与计分（缺乏互斥指纹或与主干判据重复）----
    #    错 B：相干衰减不取半（K=2.6e7）→ R 对调成 1.6e5 / 1.4e5。
    scores["hit_coherence_factor"] = 1.0 if (
        in_win(1.55e5, 1.63e5) and in_win(1.33e5, 1.40e5)
    ) or in_win(2.55e7, 2.65e7) else 0.0

    #    错 C：Ω 漏掉 1/2（用 γe·δB）→ 低场塌到 5.3e4。
    scores["hit_omega_no_half"] = 1.0 if in_win(5.10e4, 5.50e4) else 0.0

    #    错 E：弱混合一级速率近似（忽略三重态回流）→ R≈1.1e6 / 7.8e5。
    #    注意不能用 1.0e6 附近做指纹——γφ=1.00e6 s^-1 是题给参数，正确答复必然出现。
    scores["hit_weak_mixing"] = 1.0 if (
        in_win(7.4e5, 8.2e5) or in_win(1.04e6, 1.12e6)
    ) else 0.0

    #    错 F：超精细项用整个 A 而非 mA=±A/2 → 低场 2.6e4。
    scores["hit_hyperfine_or_sign"] = 1.0 if in_win(2.55e4, 2.70e4) else 0.0

    #    陷阱：只交付一个磁场的 R。
    scores["hit_partial_answer"] = 1.0 if (
        scores["target_R_low"] != scores["target_R_high"]
    ) else 0.0

    # 代码侧最终答复证据分：只反映最终答案是否可自动确认。
    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)

    return scores
```

## LLM Judge Rubric

大模型评分负责**过程、概念和逻辑**，不重复评价代码已经检查过的 R 数值命中与相位结论。若代码侧显示 R 错误，大模型仍应按过程质量独立评分，但不能替代最终答案硬检查。

本题的特殊性：题目只要求**两位有效数字**，这让"K 漏掉纯退相干 γφ"这一实质建模错误在最终数字上被舍入完全抹平（1.2680e5→1.3e5、1.4855e5→1.5e5，两个磁场都撞上标准答案）。因此**"我算出 1.3×10⁵ 和 1.5×10⁵ 了"不构成建模正确性的证据**。裁判必须看模型是否把 ρST 的衰减写成 `(kS+kT)/2+γφ`、是否用了**精确积分解**而非弱混合近似、是否识别高场的**精确抵消**，而不是看它报的两位数字对不对。

**分档的闸门设在可核验的产物上，不设在"有没有讲理由"上**。这是本题分档设计的硬约束：本题的正确解法只有一条路，做对的模型会给出同一组公式和数值，若把 1.0 档统一压在"是否说明物理来源"，四个 Criterion 就退化成同一个风格轴（答复简洁与否），做对的模型会一起塌到同一档、彼此无法区分。因此每个 Criterion 的高档各自绑定**一件互相独立、可回溯到答复原文的产物**：C1 绑 K 是否落到数值、C2 绑单位闭合是否显式、C3 绑动力学方程与排除弱混合的声明与初态权重依据、C4 绑抵消是否给出相消两项的数值。四件产物之间不相关，一个答复可以只命中其中两三件——这才是分档能拉开距离的前提。裁判据此判档时，**必须在 reason 里点出命中或缺失了哪一件产物**，不得只写"未说明理由"。

**1.0 档以本题的 SFT 标准答案为上锚**。分档不得依据任何被测答复来设定，只能依据 `# SFT标准-response` 段实际交付的内容：标准答案在某个 Criterion 上做到什么程度，那个程度就是 1.0，不得再往上加码。据此本题四项的 1.0 分别锚定在——C1 写出两项并各自归因（Haberkorn 反应损失 / 题给纯退相干）且落到 1.35×10⁷；C2 三处基准正确、至少一处给出理由、并留下 δB 的 mT 数值与 mT→T 换算；C3 写出可积分的动力学方程、得到精确解与 q_m、明确排除弱混合近似（给出 |Ω|/K 数值或声明"不要求 |Ω|≪K"二者之一即可）、并给出核组态等权的题给依据；C4 给出相消两项的数值并据此得 Ω₊=0、ΦS(+)=1，同时给出高场 m=−1/2 的 δB₋。

超出标准答案的增益——Kaptein 规则符号交叉校验、抵消点残余量的量化（~10² s⁻¹、α~10⁻⁸）、严格权重 w±=(1±P_eq)/2 的显式保留、点出 200.23 是为抵消而特意选取的构造场、两个磁场 P产物 相差二十余倍而 R 只差 12% 的对照解释——**一律不作为任何档位的前置条件**，裁判可在 reason 中记录为亮点，但不得因其缺失而下调档位。反过来，这些增益也不能把一个缺了上述四件产物的答复补到高档。

### Criterion 1: 相干衰减常数的两项构成（Weight: 25%）

**Score 1.0**: 写出 `K=(kS+kT)/2+γφ` 并**落到数值 1.35×10⁷ s⁻¹**，两项各自归因到来源——一项是 Haberkorn 反应损失作用在 ρST 上（对应 kS、kT 两个通道），另一项是题给纯退相干 γφ 按 `(dρST/dt)φ=−γφρST` 直接叠加。（标准答案即写到此处，不要求进一步论证"为何取算术平均"。）
**Score 0.8**: 表达式与数值 1.35×10⁷ 都给出、两项齐全，但两项的来源都只是并列摆出、未与 Haberkorn 反应损失 / 题给退相干定义挂钩。
**Score 0.6**: 两项都写进了公式且后续计算用对，但**只停在符号式、从未落到 1.35×10⁷ 这个数值**——本题的 has_K 判据正是为此设置：不给数值时，读者无法从答复本身排除"漏掉 γφ"（该错在两位有效数字下与标准解不可分）。
**Score 0.3**: 只用 Haberkorn 项 `(kS+kT)/2=1.25×10⁷` 而漏掉 γφ，或只用 γφ 而漏掉反应损失。
**Score 0.0**: 用 `kS+kT` 不取半（K=2.6×10⁷，把 R 对调成 1.6e5/1.4e5），或把 K 当成 kS、kT 中的某一个，相干衰减的物理来源整体没建立。

### Criterion 2: S–T₀ 耦合的构造与基准（Weight: 25%）

**Score 1.0**: 写出 `Ω_m=(γe/2)[(Δg/g)B+mA]`，三处基准正确，**完成 mT→T 的单位闭合并留下可核验的数值痕迹**（给出两个磁场下 δB_m 的 mT 数值，或给出 (Δg/g)γe、γeA 这类换算系数），并说明至少一处基准的理由（标准答案给的是"γe 按平均 g 因子定义，故 g 差产生的有效磁场差为 (Δg/g)B"）。
**Score 0.8**: 表达式与三处基准正确、单位闭合的数值痕迹在（δB 的 mT 值或换算系数至少给出一处），但三处基准的理由全部缺失、只作公式搬用。
**Score 0.6**: 表达式与三处基准正确，但**单位闭合没有留下痕迹**——只报了 Ω/q/α 这类下游量的数值，读者无法从答复核对 mT→T 是否处理正确，也无法核对 mA=±0.100 mT 这一步。
**Score 0.3**: 有一处基准错但结构仍在：用 `Δg·B`（破坏高场抵消）、用整个 A（超精细贡献翻倍）、或漏掉 1/2 因子；其余部分自洽。

### Criterion 3: 精确积分解、动力学方程与初态依据（Weight: 25%）
