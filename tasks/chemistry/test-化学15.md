# 构造高质量-query

低温尾气库在100.0 K、p°=1 bar计算2NO+O₂⇌2NO₂,将NO、O₂内配分近似为2T/(c₂B)和3T/(2c₂B)。NO为X²Π,B=1.696 cm⁻¹,两Ω项相隔123.15 cm⁻¹,E/(hc)=TΩ+B[J(J+1)−Ω²]。¹⁶O核自旋为0；O₂为X³Σg⁻,B=1.43768 cm⁻¹,E/(hc)=B[N(N+1)−2]+δ,J=N+1、N、N−1时δ依次为0、2.084、3.961 cm⁻¹。NO₂及其余自由度不变。取c₂=1.4387769 K·cm,R=8.3144626 J·mol⁻¹·K⁻¹,求精确处理这些能级后标准反应熵相对数据库值的修正。

# SFT标准-response

设某物种由数据库近似内配分函数 q_ap 改为精确能级配分函数 q_ex。其标准摩尔熵修正为
δS°/R=ln(q_ex/q_ap)+U_ex/(RT)−U_ap/(RT)。
题给两种数据库近似式均正比于 T,因此 U_ap/(RT)=∂ln q_ap/∂ln T=1。NO₂、平动、振动及标准压力项在两种模型间不变,故最终只需计算 NO 和 O₂ 的内部熵修正。

1. NO

无量纲转动参数和自旋—轨道间隔为
x=c₂B/T=(1.4387769×1.696)/100.0=0.02440166,
x_SO=c₂×123.15/T=1.7718538。

NO 的 π* 轨道少于半充满,按 Hund 第三定则,²Π₁/₂为低能项、²Π₃/₂为高能项。每个 |Ω| 梯级具有 ±Ω 二重简并,每个 J 又有空间简并度 2J+1。因此
q_NO,ex=2Σ_{J=1/2,3/2,…}(2J+1)e^{-x[J(J+1)−1/4]}
+2e^{-x_SO}Σ_{J=3/2,5/2,…}(2J+1)e^{-x[J(J+1)−9/4]}。

两个不含 ±Ω 外因子 2 的数值贡献分别为
q_{1/2}^{raw}=41.31476,
q_{3/2}^{raw}=7.02283,
故
q_NO,ex=2(41.31476+7.02283)=96.6752。

数据库近似值为
q_NO,ap=2T/(c₂B)=81.9617。
于是
ln(q_NO,ex/q_NO,ap)=ln(96.6752/81.9617)≈0.1651。

由同一组能级作 Boltzmann 平均,得到
U_NO,ex/(RT)≈1.24939,
而 U_NO,ap/(RT)=1。因此
δS°(NO)/R≈0.1651+1.24939−1=0.4145,
δS°(NO)≈0.4145R≈3.45 J·mol⁻¹·K⁻¹。

这里不能只使用 R ln(q_ex/q_ap),因为自旋—轨道上能级的热占据还改变了平均内能项。

2. ¹⁶O₂

¹⁶O 核自旋 I=0。对 X³Σg⁻ 基态,交换对称性只允许奇数 N；在显式限制为奇数 N 后,不应再额外除以对称数 2。

令
x_O2=c₂B/T=(1.4387769×1.43768)/100.0=0.02068501,
d₁=c₂×2.084/T=0.0299841,
d₂=c₂×3.961/T=0.0569900。

对每个奇数 N,J=N+1、N、N−1 三支的简并度分别是 2N+3、2N+1、2N−1。因此
q_O2,ex=Σ_{N=1,3,5,…}e^{-x_O2[N(N+1)−2]}
×[(2N+3)+(2N+1)e^{-d₁}+(2N−1)e^{-d₂}]。

逐项求和得
q_O2,ex≈74.27。
数据库近似为
q_O2,ap=3T/(2c₂B)=72.52,
所以
ln(q_O2,ex/q_O2,ap)≈0.0239～0.0240。

按同一能级求平均得到
U_O2,ex/(RT)≈0.9736～0.9737。
故
δS°(O₂)/R≈0.0239+0.9736−1≈−0.0024,
δS°(O₂)≈−0.02 J·mol⁻¹·K⁻¹。

3. 反应熵修正

对反应 2NO+O₂→2NO₂,NO₂ 不变,因此
δ(ΔrS°)=−2δS°(NO)−δS°(O₂)。
代入上述结果:
δ(ΔrS°)≈−2(3.45)−(−0.02)
≈−6.87 J·mol⁻¹·K⁻¹。

所以
ΔrS°精确−ΔrS°数据库≈−6.87 J·mol⁻¹·K⁻¹。
负号表示数据库近似把该反应在 100.0 K、1 bar 标准态下的标准反应熵高估了约 6.87 J·mol⁻¹·K⁻¹。

    scores["o2_odd_N_restriction"] = 1.0 if (o2_num and o2_sem) else 0.0

    # ---- 5. O₂ 熵修正落到数值（负、量级 1e−2）----
    scores["o2_entropy_correction"] = 1.0 if (
        in_win(-0.01900, -0.01875)      # δS(O2)=-0.01889

    #    「²Π₁/₂为低能项、²Π₃/₂为高能项」，跨度一旦吃分隔符就会把正确归属读成说反。

              r'最高|upper|higher')

    _P32 = r'(?:2?\s*π\s*3\s*/\s*2|ω\s*[=≈]\s*3\s*/\s*2)'

        assign_ok and not assign_negated
        and scores["target_reaction_entropy_correction"] == 1.0
    ) else 0.0

        or in_win(72.49, 72.55)       # q_O2,ap=72.5163

        or in_win(0.97340, 0.97400)   # U_O2,ex/(RT)=0.97375

        or in_win(2.4395, 2.4410)     # θ_rot(NO)=2.44017

        "target_reaction_entropy_correction": 0.26,
        "internal_energy_term": 0.20,
        "no_joint_partition_function": 0.16,
        "o2_odd_N_restriction": 0.16,
        "o2_entropy_correction": 0.10,
        "hund_lower_pi_half": 0.06,
        "derived_intermediate": 0.06,

    scores["hit_ln_q_only"] = 1.0 if (
        in_win(1.3700, 1.3760) or in_win(-2.740, -2.712)
    ) else 0.0

    #    错 B：漏 ±Ω 外因子 2 → δS(NO)=−2.3169、ln 比=−0.52804、终值 +4.6526。
    #    ⚠️ 不取 48.34（与正确解的括号内小计 48.33759 同数）。
    scores["hit_missing_pm_omega"] = 1.0 if (
        in_win(-2.3220, -2.3120) or in_win(-0.5285, -0.5276)
        or in_win(4.645, 4.660)

    #    错 A：忽略 ²Π₃/₂ 上梯级 → q_NO,ex=82.6295。

        (in_win(82.60, 82.66) or in_win(95.39, 95.45)
         or in_win(3.3540, 3.3600))
        and scores["no_joint_partition_function"] == 0.0
    ) else 0.0

    #    错 D/E/F/F′：O₂ 的奇偶 N 与对称数口径错 → q_O2,ex 落到四个互斥窗之一。

        (in_win(149.50, 149.70) or in_win(37.10, 37.18)
         or in_win(74.76, 74.84) or in_win(75.28, 75.36)
         or in_win(-12.70, -12.58) or in_win(-1.130, -1.090)
         or in_win(5.735, 5.752) or in_win(-5.790, -5.774))
        and scores["o2_odd_N_restriction"] == 0.0
    ) else 0.0

    #    错 I/J/K：符号整体反、漏计量数 2、O₂ 项符号摆反。
    #    ⚠️ 以「终值未落窗」为门：标准答案末句写「高估了约 6.87 J·mol⁻¹·K⁻¹」，
    #    那是个裸正数，与错 I 的交付值同窗，不加门会反扣标准答案（A2.4）。
    scores["hit_sign_or_stoich"] = 1.0 if (
        (in_win(6.855, 6.890) or in_win(-3.440, -3.415)
         or in_win(-6.925, -6.900))
        and scores["target_reaction_entropy_correction"] == 0.0
    ) else 0.0

    #    错 G：Hund 说反（²Π₃/₂ 在下）。数值上不可分，只能靠文字。
    scores["hit_pi_three_half_lower"] = 1.0 if assign_negated else 0.0

    penalty = 0.25 * (scores["hit_ln_q_only"] + scores["hit_missing_pm_omega"]
                      + scores["hit_no_ladder_error"]
                      + scores["hit_o2_parity_or_sigma"]
                      + scores["hit_sign_or_stoich"]
                      + scores["hit_pi_three_half_lower"])

    # ---- 零权重追溯字段 ----
    scores["trace_no_extra_sigma"] = 1.0 if has_any(text, [
        r'(?:' + _NEG + r')[^。；\n]{0,12}(?:再|额外|重复)?[^。；\n]{0,6}'
        r'除[^。；\n]{0,8}(?:对称数|σ|2)',
        r'(?:对称数|σ)[^。；\n]{0,14}(?:已|无需|不必|不再)',
    ]) else 0.0
    scores["trace_uap_equals_one"] = 1.0 if has_any(text, [
        r'u\s*_?\s*ap\s*/?\s*\(?\s*rt\s*\)?\s*[=≈]\s*1(?![\d.])',
        r'(?:正比于|∝)\s*t[^。；\n]{0,24}(?:1|一)',
        r'∂\s*ln\s*q[^。；\n]{0,14}∂\s*ln\s*t',
    ]) else 0.0
    scores["trace_no2_unchanged"] = 1.0 if has_any(text, [
        r'no2[^。；\n]{0,20}(?:不变|相同|抵消|无(?:需)?(?:修正|变化))',
        r'(?:平动|振动|标准压力)[^。；\n]{0,20}(?:不变|抵消|相同)',
    ]) else 0.0

    scores["auto_final_answer_score"] = round(
        max(0.0, min(1.0, earned - penalty)), 3)
    return scores
