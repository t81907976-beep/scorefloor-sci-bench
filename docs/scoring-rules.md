# Benchmark 总计分规则
权重：**成功率 60% / 效率 20% / 一致性 20%**

适用范围：单任务重复运行 5 次，所有得分统一归一化至 **0~1 区间**，按「单次运行得分 → 单任务 5 次聚合得分 → 全 Bench 总分」层级计算。

---

## 一、基础定义
统一统计口径与核心变量：

1. **成功率子维度**：最终答复分、步骤分、逻辑分，均为 `0~1` 分，`1` 表示完全正确，`0` 表示完全错误。
2. **基准步骤数** $N_0$：Benchmark 标准答案的标准有效步骤数，即最优解步骤数。
3. **实际步骤数** $N$：模型单次输出的**有效步骤数**，仅统计正确、相关的逻辑或操作节点，排除错误、冗余、重复、无关步骤。
4. **效率上限** $E_{max}$：推荐值 `1.5`，表示步骤精简至基准的约 `67%` 时效率项拿满分，避免跳步刷分。
5. **5 次运行标记**：第 $i$ 次运行，$i=1,2,3,4,5$；对应单次成功率分为 $S_i$，对应实际步骤数为 $N_i$。

---

## 二、成功率得分（权重 60%）
### 1. 单次运行成功率分
三个子维度等权平均：

$$S_i = \frac{最终答复分 + 步骤分 + 逻辑分}{3}$$
### 2. 单任务总成功率分
5 次运行得分取算术平均值：

$$S_{success} = \frac{S_1 + S_2 + S_3 + S_4 + S_5}{5}$$
---

## 三、效率得分（权重 20%）
核心逻辑：步骤数越少，效率越高；以基准步骤为锚点反比例浮动，并通过上限截断保证权重有效。

### 1. 单次运行原始效率系数
$$E_{raw_i} = \frac{N_0}{N_i}$$
* 当 $N_i = N_0$ 时，$E_{raw_i}=1$，与基准效率持平。
* 当 $N_i < N_0$ 时，$E_{raw_i}>1$，步骤精简，效率加分。
* 当 $N_i > N_0$ 时，$E_{raw_i}<1$，步骤冗余，效率减分。

### 2. 单次运行归一化效率系数
按上限截断，统一至 `0~1` 区间，保证三大指数量级一致、权重配比有效：

$$E_{norm_i} = \min\left(\frac{E_{raw_i}}{E_{max}},\ 1\right)$$

**反向激励闸门（2026-08-06 起）**：步骤分为 0 的 run（一步未推、直接报结论）
效率系数一律记 0，不走上式：

$$E_{norm_i} = 0 \quad \text{当}\ \text{step\_score}_i = 0$$

原式只看步骤数、不看有没有在解题，`N_i` 越小分越高，于是空转 run 拿满分。
0804 实测化学09 的 run2/run5 步骤分与逻辑分双 0、却各拿 $E_{norm}=1.0$，
而唯一真在推导的 run1 因步骤多被压到 0.4；全库 $\text{corr}(S_{success},
\overline{N_i}) = +0.5835$，与「效率」立意相反。

⚠️ 闸门**只判是否为 0**，不设阈值。`step_score` 由裁判给出，换裁判会整体平移标度，
任何非零阈值都会跟着漂；且阈值架在结果分上时，地板本就高于阈值的题等于没有闸门。

### 3. 单次运行效率得分
与单次成功率绑定，体现「有效成功的效率」原则：

$$S_{eff_i} = S_i \times E_{norm_i}$$
### 4. 单任务总效率分
5 次运行效率分取算术平均值：

$$S_{eff} = \frac{S_{eff_1} + S_{eff_2} + S_{eff_3} + S_{eff_4} + S_{eff_5}}{5}$$
---

## 四、一致性得分（权重 20%）
核心逻辑：基于 5 次成功率得分的波动计算，波动越小，一致性得分越高。

### 1. 基础统计量
5 次成功率得分的平均值为 $\mu = S_{success}$，总体标准差为：

$$\sigma = \sqrt{\frac{\sum_{i=1}^{5}(S_i - \mu)^2}{5}}$$
### 2. 变异系数
$$CV =
\begin{cases}
\frac{\sigma}{\mu}, & \mu > 0 \\
0, & \mu = 0
\end{cases}$$
5 次全错时视为稳定表现，变异系数直接记为 `0`。

### 3. 单任务一致性得分
$$S_{consistency} = \max(1 - CV,\ 0)$$
得分范围为 `0~1`，数值越高代表模型输出越稳定。

---

## 五、最终总分计算
### 1. 单任务总分
按权重合成：

$$S_{task} = S_{success} \times 0.6 + S_{eff} \times 0.2 + S_{consistency} \times 0.2$$
### 2. 分学科总分
得分取算术平均值：

$$S_{total} = \frac{\sum_{k=1}^{n}S_{task_k}}{n}$$
其中，$n$ 为测试任务总数。

---

## 六、边界与异常规则
1. **实际步骤数 **$N=0$：原始效率系数按 $E_{max}$ 计，但成功率中的「步骤分」「逻辑分」将因缺失推导过程扣分，避免跳步刷分。
2. **含错误或无效步骤**：错误、无关、重复步骤不计入有效步骤数 $N$，同时在成功率的「步骤分」维度扣减对应分数，正确性与效率维度独立评判。
3. **步骤粒度不匹配**：以标准答案的步骤粒度为统一标准，合并模型过度拆分的细粒度步骤，拆分模型过度合并的粗粒度步骤，保证统计口径一致。
4. **步骤分为 0**（2026-08-06 补）：$E_{norm}=0$，见第三节反向激励闸门。与规则 1 的区别是判据不同——规则 1 看 $N=0$（没报步骤），本条看裁判判定「没有推导」，两者可各自独立触发。

---

## 七、计算示例（单任务）
**基础参数**：基准步骤数 $N_0=10$，效率上限 $E_{max}=1.5$

|运行次数|最终答复|步骤|逻辑|单次成功率 $S_i$|实际步骤 $N_i$|原始系数 $E_{raw}$|归一化系数 $E_{norm}$|单次效率分 $S_{eff_i}$|
|-|-|-|-|-|-|-|-|-|
|1|1|1|1|1.000|8|1.250|0.833|0.833|
|2|1|0.5|1|0.833|10|1.000|0.667|0.556|
|3|0|0.5|0.5|0.333|12|0.833|0.556|0.185|
|4|1|1|0.5|0.833|9|1.111|0.741|0.617|
|5|1|0.5|1|0.833|11|0.909|0.606|0.505|

### 计算结果
1. 总成功率分：$S_{success}=0.766$
2. 总效率分：$S_{eff}=0.539$
3. 一致性分：$\mu=0.766$，$\sigma \approx 0.226$，$CV \approx 0.295$，$S_{consistency}=0.705$
4. 单任务总分：

$$S_{task} = 0.766 \times 0.6 + 0.539 \times 0.2 + 0.705 \times 0.2 \approx 0.709$$
